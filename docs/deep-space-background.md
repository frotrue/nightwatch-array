# 확장 이후 우주 배경

2026-09-16 사용자가 목업을 승인하고 별자리 확장 이후에만 적용하도록 요청했다.

## 적용 범위

- `galactic_reference_frame` 연구의 기존 해금 상태를 사용한다. 새 연구·저장 키는 없다.
- 확장 전에는 기존 하늘·산·관측소·새벽 연출이다. 확장 후에는 지평선 없는 은하수·먼지층 배경이다.
- 성도 확장 연출, 실제 천체, 유성 활동 영역, 관측 UI, 관측·정산·연구 흐름과 보상은 유지한다.
- 관측 중 배경은 정적이다. 확장 후 정산에서는 기존 1.1초 연출 시계로 배경을 60% 밝기까지 낮춘다.
  정산 UI의 0.3초 표시와 즉시 계속하기 동작은 기존 경로다. 동작 강도 0%는 즉시 최종 상태가 된다.
- 초기/확장 슬롯 전환과 런 리셋은 실제 연구 소유에 맞는 배경을 즉시 선택한다.
  정산 저장을 불러올 때 마지막 시계 동기화가 완료된 새벽/어두워짐을 지우던 동작도 함께 교정했다.

## 배경 자료와 렌더링

`resources/textures/deep_space.png`는 사용자가 승인한 이미지 생성 목업에서
천체·유성·UI·개별 은하 그림을 제거해 만든 배경 전용 원본이다. 이미지 생성 도구로 제작했고,
실제 천문 관측 사진이 아니다. 현재 파일은 3840×2160 RGB PNG다.
2026-09-16 사용자의 4K 요청에 따라 기존 1672×941 원본을 입력으로 OpenAI Image API의
`gpt-image-2` 편집을 1회 사용했다(`size=3840x2160`, `quality=high`, PNG).
후처리 확대 없이 API가 반환한 파일을 사용하며, 미세 별빛과 먼지층은 생성 복원되어
원본과 픽셀 단위로 같지는 않다. 게임의 밝기 배율 0.50은 유지한다.
[사용한 최종 프롬프트](deep-space-4k-prompt.txt)를 보존한다. 원본 PNG는 10,507,461바이트이며
SHA-256은 `d5e9cdff95abbfe45071bc4ff417da0a0bc69d05fc4dd06b65c033bf5d33afa9`다.
재생성 지시의 핵심은 다음과 같다.

> 승인 목업의 어두운 남청색 하늘, 좌하단에서 우상단으로 흐르는 희미한 은하수와
> 불규칙한 먼지층을 유지한다. 모든 전경 천체·유성·UI·문자·개별 은하를 제거하고
> 작은 어두운 배경 별과 넓은 여백으로 자연스럽게 채운다.

메인 씬이 텍스처를 바인딩한다. Starfield의 기존 절차적 배경 소유 범위 안에서
텍스처 사각형 하나로 그리며, 종횡비를 보존하고 4% 여유 영역을 확보한다.
기본 색 배율은 0.50이다. 2026-09-16 배경이 너무 화려하다는 사용자 피드백에 따라
0.82에서 낮춰 은하수 띠와 배경 별빛을 누르고 실제 관측 천체가 더 잘 드러나게 했다.
기존 별 레이어를 중복해서 겹치지 않는다. 배경 이미지는 블랙홀 등 기존 굴절 경로에 보인다.
매 프레임 입자 생성·노이즈 계산·화면 복사는 추가하지 않는다.

## 검증 상태

### 4K 배경

API 반환 PNG와 두 렌더러의 `07_resize_3840x2160.png` 파일이 실제 3840×2160인지
파일을 열어 확인했다. `deep_space_background_review`의 기존 크기 변경 목록에 4K를 추가했으며
Vulkan/Mobile과 OpenGL/Compatibility에서 모두 통과했다. 한영 천체/UI 가독성,
정산·리셋과 4K 화면의 배경 경계도 확인했다. 평균 RGB 밝기는 원본보다 증가하지 않았다.
화면 검사 로그는 `build/deep_space_review/4k-logs/`에 있다.
기능 검사 31개와 Windows 내보내기도 통과했으며,
`build/validation/20260916T115349176Z_49cee95e/summary.json`에 기록했다.
갱신한 실행 파일은 임시 APPDATA에서 두 렌더러로 각각 30프레임 구동 후 정상 종료했다.

### 밝기 완화

2026-09-16 기본 밝기 0.50을 적용한 뒤 기능 검사 31개와 Windows 내보내기를 통과했다.
기록은 `build/validation/20260916T113716649Z_ea5cb9de/summary.json`에 있다.
Vulkan/Mobile과 OpenGL/Compatibility에서 `deep_space_background_review`와
`background_batch_render_test`를 각각 통과했다. 한영 천체/UI, 정산 어두워짐과
크기 변경 캡처를 확인했으며, 이전 밝기 0.82의 같은 합성 화면과 비교했다.
현재 캡처는 `build/deep_space_review/<renderer>/`, 이전 밝기 비교 캡처는
`before-softening/`, 이번 로그는 `softening-logs/`에 있다.

### 최초 배경 적용 검증

2026-09-16 메인 Windows 데스크탑에서 PR #22의 `981c849`와 아래 검증 보완을 확인했다.
Godot 4.7.2, NVIDIA RTX 3060을 사용했다.

- `tools/validate.ps1 -Build`: 기능 검사 31개와 Windows 내보내기 통과.
  실제 해금·슬롯 전환·정산 복원·다음 관측·리셋·종횡비 검사를 포함한다.
  기록: `build/validation/20260916T085647834Z_517c19c7/summary.json`.
- Vulkan/Mobile 및 OpenGL/Compatibility 각각 `deep_space_background_review`,
  `background_batch_render_test`, `meteor_batch_render_test`, `effect_instances_render_test` 통과.
  종료 코드 0, 각 PASS 표식과 예상 밖 엔진/스크립트 오류 없음을 확인했다.
- 두 렌더러의 확장 전후·정산·한영 천체/UI·크기 변경 캡처를 육안 확인했다.
  은하수 위의 실제 천체와 UI를 구분할 수 있고 배경 내부 경계나 늘어짐은 발견하지 못했다.
  관측 중 배경 유지, 정산 어두워짐과 리셋 복원은 픽셀 비교도 통과했다.
  캡처와 manifest는 `build/deep_space_review/<renderer>/`, 로그는 `local-logs/`에 있다.
- 창 1440×900과 2560×1080에서는 기존 16:9 유지 설정 때문에 실제 게임 캡처가
  각각 1440×810과 1920×1080이다. manifest에 창과 렌더 크기를 별도로 기록한다.
  1.5배 카메라 후퇴를 확인했으며 다른 종횡비의 배경 사각형은 기능 검사에서 별도로 검증했다.
- 영문 전환 후 정지된 천체 본체가 캡처에서 사라지는 검사 도구 문제를 수정했다.
  기존 미리보기의 캔버스 갱신 방식을 재사용하고, 한영 캡처의 천체 영역이 같은지 검사한다.
- 최종 Windows 실행 파일을 다시 내보내고 두 렌더러에서 각각 30프레임 실행 후 정상 종료했다.
  임시 APPDATA를 사용해 플레이어 저장과 설정을 격리했다. 최종 실행 파일 SHA-256:
  `40a3733bb8ec99b6ec22865aaf3f86f1707dfdc3ebfccf11d86c1c2fbc197082`.

초기 원격 CI 실패는 오디오 장치 부재와 `build/native/*.obj`의 잘못된 Godot 임포트였다.
화면 검사에 Dummy 오디오를 지정하고 `build/.gdignore`를 버전 관리에 포함했다.
수정한 원격 CI 자체는 이번 로컬 검증에서 재실행하지 않았다.
캡처는 합성 진행 상태이며 사람의 장시간 플레이 검증을 의미하지 않는다.
