# 화이트홀 연출 시제품

사용자가 화이트홀의 디버그 소환과 외형 실험을 요청해 만든 시제품이다.
후속 피드백은 **블랙홀처럼 약간 실사에 가까운 천체감과 강한 첫인상**이다.
이에 따라 초기의 매끈한 백색 원·동심원 파동을, **눈부신 중심·층이 겹치는
가스 원반·불규칙한 방출 흐름·주변 별빛 굴절**로 대체했다.

## 비교할 두 가지 효과

| 효과 | 표현 | 비교할 점 |
|---|---|---|
| 난류 원반형 — 기본 | 차등 회전하며 바깥으로 흐르는 가스, 밝은 중심을 감싸는 앞뒤 원반, 희미한 외곽 가스 | 빛·그늘의 대비와 겹침이 천체의 깊이감을 주는지 |
| 양극 제트형 | 같은 원반에서 양쪽으로 뻗는 불규칙하고 가느다란 가스 분출 | 기본형보다 인상이 강한지, 원반과 제트가 한 천체로 보이는지 |

[NASA 블랙홀 시각화](https://svs.gsfc.nasa.gov/13326/)의 빛나는 가스층,
밝기 비대칭과 겹쳐 보이는 원반을 시각적 참고로 삼았다. 화이트홀 외형을
예측하는 물리 시뮬레이션은 아니며, 방출 원반과 제트는 게임용 상상도다.
해당 자료의 이미지를 게임 텍스처로 사용하지 않는다.

가스는 셰이더의 여러 크기 난류와 전단 흐름으로 그린다. 부드러운 중심부에서
외곽의 낮은 밝기까지 변화시키고, 규칙적인 선·입자 배치를 없앤다.
배경 별빛에는 기존 블랙홀의 렌즈 셰이더를 재사용한다. 광학 노드는 하늘 직후,
유성·관측 장비보다 먼저 그려지므로 실제 표적의 관측 위치를 굴절시키지 않는다.
인스턴스마다 독립 재질이며, 보이는 활성 인스턴스당 화면 복사 1회가 필요하다.
숨김·화면 밖·동작 강도 0·완전 투명·만료 상태에서는 복사를 끈다.
전체 화면 플래시는 없고, 밝기 호흡은 최대 ±1.5%다.

## 게임에서 확인하기

- `Ctrl+Shift+W`: 커서의 월드 위치에 소환한다. 카메라가 멀어져도 소환 시
  외형의 화면 크기를 맞춘다. 해금 연구 없이 사용할 수 있다.
- `Ctrl+Shift+E`: 원반형과 제트형을 전환한다. 이미 표시된 화이트홀에도 적용된다.
- 동시에 최대 3개. 관측 중 16초 후 사라지며, 시작 0.6초와 마지막 1.2초에
  부드럽게 나타나고 사라진다. 회차 종료·새 런·리셋·불러오기 때 정리한다.
- 성도가 열린 일시정지 중에도 소환·전환 키는 처리하지만 시간은 흐르지 않는다.
- 동작 강도 0에서는 가스 흐름을 멈추고 분출·별빛 굴절을 끈다.
  정적인 원반·중심·후광과 시간에 따른 소멸은 유지한다. 화면 번쩍임을 끄면 밝기 호흡도 끈다.

현재는 외형을 판단하기 위한 관측 불가능한 시각 효과다. 자연 출현 표,
천체 생성 자리, 관측·접시 표적, 보상, 중력, RNG, 저장에는 참여하지 않는다.
실제 천체를 밀어내거나 방출하는 기능과 연구 해금은 후속 설계 대상이다.

## 구현과 검증

- `scenes/white_hole_preview.tscn`: 인스턴스마다 독립 재질을 갖는 외형과 배경 렌즈.
- `resources/shaders/white_hole_emission.gdshader`: 두 방출 효과.
- `scripts/debug_celestial_layer.gd`: 디버그 소환 한도·전환·정리.
- `scripts/white_hole_preview.gd`: 고정 틱 수명과 셰이더 시간.
- `tests/white_hole_test.gd`: 단축키 경로, 한도, 저장/RNG 격리, 일시정지,
  접근성, 만료 후 재소환, 불러오기·리셋·회차 종료 검증. 빠른 게이트에 포함한다.
- `tests/white_hole_review.gd`: 실제 렌더러에서 두 효과, 제한된 그리기 범위,
  동작 줄이기의 화면 안정성, 배경 굴절·전경 보존, 3개 중첩과 제거 후 잔상 검증.

```powershell
& $godot --path . --script res://tests/white_hole_review.gd -- --animate
& $godot --path . --rendering-method gl_compatibility --rendering-driver opengl3 --script res://tests/white_hole_review.gd
```

캡처는 `build/white_hole/<렌더러>/`에 저장한다. `--animate`는 두 효과를
동시에 보여주는 4초·18fps 비교용 PNG 시퀀스도 만든다. 테스트용 장면이며
사용자의 저장·설정을 변경하지 않는다.
