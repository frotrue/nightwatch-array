# 화이트홀 관측 시제품

사용자가 화이트홀의 디버그 소환·외형 실험에 이어 이동·관측·유성 방출을 승인한 시제품이다.
이번 범위는 디버그 소환으로 기능을 완성하는 것이며 자연 출현·연구 해금은 보류한다.
현재 사용자 방향은 **과도하게 화려하지 않으면서 어느 정도 현실적인 천체감**이다.
작은 밝은 중심과 그늘이 남는 가스 원반, 느린 흐름과 주변 별빛 굴절로 깊이를 준다.
초기의 매끈한 백색 원·동심원 파동을 가스층으로 대체한 뒤, 화면을 지배하던
중심의 면적·외곽 번짐·제트의 길이와 밝기를 낮췄다.

## 이동·관측·방출

- `Ctrl+Shift+W`로 커서에 관측 가능한 화이트홀을 소환한다. 스폰 때 하나의
  진행 방향과 원반 자세를 정하며 기본 속도는 화면 기준 22px/s다.
  방향은 유지하고 자세는 약 ±3도만 흔들린다. 원반의 양극 축은 진행 방향을 따른다.
- 기본 수명 16초, 관측 시간 3.6초, 기본 데이터 160이다. 기존 수명·관측·보상
  연구와 품질 배율을 적용하며 커서 및 접시로 관측한다. 초신성 자동 완료에서는 제외한다.
- 관측 후반에는 희미한 제트가 준비된다. 완료 시 이동을 멈추고 양극 제트로
  전환한다. 1.4초 동안 본체가 수축하고, 마지막에는 제트 잔광도 사라진다.
- 완료 0.1초 뒤부터 0.18초 간격으로 6번, 매번 4개씩 총 24개를 방출한다.
  양극에 각각 12개이며 일반 8·고속 4·분열 4·발광 4·파편 4개로 구성한다.
  부채꼴로 퍼지는 방향과 속도가 서로 다르며 이후 각 종류의 이동·분열 규칙을 따른다.
- 방출 자체로 유성 보상을 지급하지 않는다. 새 표적을 관측해야 기존 경로로
  보상을 얻는다. 직접 방출된 유성은 다른 생성 효과처럼 메아리·사자자리의
  첫 발동을 다시 유발하지 않으며 모듈 파편과 일반 분열 규칙은 유지한다.
- 화이트홀·항성·블랙홀·거대 유성은 방출 목록에 없다. 반복 관측으로 중복 방출할 수 없다.
  화이트홀은 동시 3개이고 일반 유성 54개 안전 예산을 공유하므로 기존 전체 상한을
  늘리지 않는다. 자리가 없으면 해당 방출을 건너뛰며 나중에 몰아서 재생하지 않는다.
- 미관측 만료 시에는 유성을 방출하지 않는다. 일시정지는 방출 일정도 멈추며,
  동작 강도 0에서도 관측 결과와 유성 개수는 동일하다. 회차 종료·리셋·불러오기는
  본체와 남은 방출을 정리한다. 비행 중 상태는 다른 일반 천체처럼 저장하지 않는다.

## 비교할 두 가지 외형

| 효과 | 표현 | 비교할 점 |
|---|---|---|
| 난류 원반형 — 기본 | 천천히 차등 회전하는 회청색·상아색 가스층, 작은 밝은 중심과 앞뒤로 겹치는 원반 | 넓은 발광 없이 빛·그늘과 겹침으로 깊이가 읽히는지 |
| 양극 제트형 | 같은 원반의 양쪽에 짧고 희미하게 이어지는 가느다란 가스 분출 | 원반보다 덜 두드러지면서 기본형과 구별되는지 |

[NASA 블랙홀 시각화](https://svs.gsfc.nasa.gov/13326/)의 빛나는 가스층,
밝기 비대칭과 겹쳐 보이는 원반을 시각적 참고로 삼았다. 화이트홀 외형을
예측하는 물리 시뮬레이션은 아니며, 방출 원반과 제트는 게임용 상상도다.
해당 자료의 이미지를 게임 텍스처로 사용하지 않는다.

가스는 셰이더의 여러 크기 난류와 전단 흐름으로 그린다. 부드러운 중심부에서
외곽의 낮은 밝기까지 변화시키고, 규칙적인 선·입자 배치를 없앤다.
가스 흐름은 첫 가스층 표현의 62% 속도이며, 촘촘한 밝은 실선 대신 넓고 부드러운
밀도층을 쓴다. 외곽 가스·원반 후광을 줄이고 중심에만 높은 밝기를 남긴다.
외형 비교용 고정 시제품은 원반 축을 약 ±14도 움직이고, 실제 관측 대상은
진행 방향을 유지하도록 ±3도로 줄인다. 시선에 대한 기울기는 서서히 변한다.
원반·후광·제트가 같은 축을 따르고, 내부 가스는 이 자세 변화와 별도로 순환한다.
모든 변화는 누적된 시각 시간만 사용하므로 일시정지·동작 강도 0에서 자세도 멈춘다.
배경 별빛에는 기존 블랙홀의 렌즈 셰이더를 재사용한다. 광학 노드는 하늘 직후,
유성·관측 장비보다 먼저 그려지므로 실제 표적의 관측 위치를 굴절시키지 않는다.
인스턴스마다 독립 재질이며, 보이는 활성 인스턴스당 화면 복사 1회가 필요하다.
숨김·화면 밖·동작 강도 0·완전 투명·만료 상태에서는 복사를 끈다.
전체 화면 플래시는 없고, 밝기 호흡은 최대 ±0.5%다.

## 게임에서 확인하기

- `Ctrl+Shift+W`: 커서의 월드 위치에 움직이는 관측 대상을 소환한다.
  카메라가 멀어져도 이동 속도와 관측 범위를 맞춘다. 해금 연구 없이 사용할 수 있다.
- `Ctrl+Shift+E`: 원반형과 제트형을 전환한다. 이미 표시된 화이트홀에도 적용된다.
- 동시에 최대 3개. 기본 수명 16초이며, 시작 0.6초 동안 부드럽게 나타난다.
  관측 완료 후 방출 연출은 별도 1.4초다. 회차 종료·새 런·리셋·불러오기 때 정리한다.
- 성도가 열린 일시정지 중에도 소환·전환 키는 처리하지만 시간은 흐르지 않는다.
- 동작 강도 0에서는 원반 방향·기울기와 가스 흐름을 멈추고 분출·별빛 굴절을 끈다.
  정적인 원반·중심·후광과 시간에 따른 소멸은 유지한다. 화면 번쩍임을 끄면 밝기 호흡도 끈다.

자연 출현 표·연구 목록은 변경하지 않는다. 디버그 소환과 방출 방향 결정은
자연 출현 RNG를 소비하지 않으며, 생성된 유성의 후속 분열·모듈은 기존 규칙을 따른다.

## 구현과 검증

- `scenes/white_hole_preview.tscn`: 인스턴스마다 독립 재질을 갖는 외형과 배경 렌즈.
- `resources/shaders/white_hole_emission.gdshader`: 두 방출 효과.
- `scripts/debug_celestial_layer.gd`: 디버그 소환 한도·전환·정리.
- `scripts/white_hole_preview.gd`: 고정 틱 수명과 셰이더 시간.
- `scripts/white_hole_meteor.gd`: 일반 Meteor를 상속한 관측 대상. 자세·광학 시간과
  완료 방출 일정을 소유하며, 유성 생성은 `meteor_spawner.gd`의 기존 경로에 맡긴다.
- `tests/white_hole_test.gd`: 단축키 경로, 한도, 저장/RNG 격리, 일시정지,
  접근성, 만료 후 재소환, 불러오기·리셋·회차 종료 검증. 빠른 게이트에 포함한다.
- `tests/white_hole_review.gd`: 실제 렌더러에서 두 효과, 제한된 그리기 범위,
  시간에 따른 자세·가스 변화와 시각 시간을 고정했을 때의 화면 안정성,
  동작 줄이기, 배경 굴절·전경 보존, 3개 중첩과 제거 후 잔상 검증.

```powershell
& $godot --path . --script res://tests/white_hole_review.gd -- --animate
& $godot --path . --rendering-method gl_compatibility --rendering-driver opengl3 --script res://tests/white_hole_review.gd
& $godot --path . --script res://tests/white_hole_review.gd -- --observe
```

캡처는 `build/white_hole/<렌더러>/`에 저장한다. `--animate`는 두 효과를
동시에 보여주는 8초·24fps 비교용 PNG 시퀀스도 만든다. 실제 애니메이션 시간과
동일한 속도이며, 공유할 때는 두 천체 주변을 잘라 GIF로 변환한다. 테스트용 장면이며
사용자의 저장·설정을 변경하지 않는다.
`--observe`는 실제 고정 틱과 입력 버퍼로 이동 중인 대상을 수동 관측하고,
유성 방출·본체 소멸까지 8초·30fps로 기록한다. `observable/`에 PNG와 결과를 남긴다.

관측·방출 시제품 검증(2026-09-15, Godot 4.7.2 / RTX 3060):

- 기본 검사 30개, 전체 경제 검사와 Windows 내보내기가 모두 통과했다. 결과는
  `build/validation/20260915T042331726Z_69cd5764/summary.json`에 기록한다.
- Vulkan·OpenGL 각각 외형·실제 관측 리뷰와 배경·유성·효과 렌더링 검사,
  총 10개 통과. 이동 표적의 입력 버퍼 관측, 24개 방출과 소멸을 확인했다.
  고정 시간·동작 줄이기·전경 보존·그리기 범위·제거 후 잔상 검사도 유지한다.
- 실제 관측 시퀀스는 `build/white_hole/<렌더러>/observable/`에 있다.
  양쪽 모두 243번째 틱에 완료하고 24개를 방출했다. 후속 분열을 포함해
  최대 36개 표적이 있었으며, 원천 화이트홀은 방출 후 제거됐다.
- 공유 GIF는 `build/white_hole/white-hole-ejection.gif`다. 실제 렌더 프레임을

  반복 재생한다. 제트·본체 수축·방출 유성과 변환 후 글자·색을 확인했다.
- 실행 파일: `C:\Users\user\Documents\ChatGPT\star\build\windows\NightwatchArray.exe`.
  내보낸 실행 파일의 팩에서도 이동·입력 관측·24개 방출·소멸 검사를 통과했다.
  `build/white_hole/exported-observable.log`에 실행 결과를 남긴다.
