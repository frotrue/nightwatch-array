# 화이트홀과 봉황자리

2026-09-15 사용자 승인으로 이동·관측·분출 시제품을 블랙홀 이후의 정식 관측 대상으로
연결했다. 과도하게 화려하지 않은 천체감을 유지하며, 작은 밝은 중심·그늘이 남는
가스 원반·느린 흐름·주변 별빛 굴절을 사용한다.

## 봉황자리와 진행

화살자리 → 게자리 → 궁수자리의 블랙홀 관측 → 블랙홀 추적 → 블랙홀 분석 →
봉황자리의 화이트홀 관측으로 이어진다. 궁수자리 전체 완성이나 모듈 수집은 요구하지 않는다.

| 연구 / 별 | 가격 | 선행 | 효과 |
|---|---:|---|---|
| 화이트홀 관측 / α Phe | 120M | 블랙홀 분석 | 화이트홀 자연 출현·양극 유성 방출 해금 |
| 밀도 높은 분출 / β Phe | 100M | 화이트홀 관측 | 방출량 24 → 36개 |
| 화이트홀 추적 / γ Phe | 80M | 화이트홀 관측 | 수동·자동 관측 속도 +50% |
| 화이트홀 탐색 / δ Phe | 100M | 화이트홀 추적 | 출현 확률 +50% |
| 분출물 분석 / ε Phe | 100M | 밀도 높은 분출 | 직접 방출된 유성의 데이터 +50% |
| 풍부한 분출 / ζ Phe | 120M | 화이트홀 탐색 + 분출물 분석 | 방출량 36 → 48개 |

6개 연구 총 620M. 기존 155개 연구의 가격·효과와 회차 길이는 유지한다.
현재 전체는 **95 + 66 = 161개 연구, 25개 별자리·169표식·168고유 천체**다.

## 자연 출현·이동·관측

- 독립 60틱 추첨의 기본 확률은 `0.005 / 60`이다. 공통 출현 배율과 화이트홀 탐색의
  ×1.5를 곱한다. 기존 종류의 순서를 유지하고 마지막에 전용 난수 스트림을 추가했다.
- 다른 천체처럼 화면 가장자리에서 정해진 경로로 진입하고 예보·접시·수동 관측을 따른다.
  스폰 시 방향과 원반 자세를 정하며 기본 속도는 22px/s, 자세는 약 ±3도 흔들린다.
  원반의 양극 축은 진행 방향을 따른다. Ctrl+Shift+W/E 디버그 비교도 유지한다.
- 기본 수명 16초, 관측 시간 3.6초, 데이터 160, 본체 반경 40이다. 기존 수명·관측·보상
  연구와 품질 배율을 적용한다. 다른 항성·블랙홀과 함께 초신성 즉시 관측에서 제외한다.
- 등장 심사에서는 관측 시간에 더해 제트 1초와 방출 유성 관측 여유 1초를 확보한다.
  회차가 거의 끝났을 때 분출할 시간조차 없는 새 화이트홀 예보를 만들지 않는다.
- 화이트홀 전용 3자리를 보장한다. 전체 안전 상한 70개 안에서 일반·파편 51,
  후기 15(기존 일반 후기 6 + 항성·블랙홀·화이트홀 각각 3), 표본 3, 거대 유성 1로 배분한다.
  완료 잔상도 자리를 차지한다. 기존 종류의 출현 확률과 자연 등장 연구 한도는 유지한다.

## 양극 방출

- 관측 후반에 희미한 제트가 준비된다. 수동·자동 완료 시 이동을 멈추고 양극 제트로
  전환한다. 1초 동안 본체가 수축하고 마지막에는 제트 잔광도 사라진다.
- 2026-09-15 후속 요청에 따라 애니메이션 중 분할 방출을 없앴다. 완료 후 1초 동안
  유성은 나오지 않고, 연출이 끝나는 틱에 24·36·48개를 한꺼번에 방출한다.
  양극의 같은 수량을 유지하며 본체는 그 틱에 숨김·제거한다.
- 일반·고속·분열·발광·파편의 5종을 섞는다. 기본 24개 구성은 일반 8개와 나머지
  각 4개다. 연구 후에도 같은 비율이다. 부채꼴 방향과 속도로 퍼지고 기존 이동·분열을 따른다.
- 방출 자체로 보상을 지급하지 않는다. 새 표적을 관측해야 데이터가 들어온다.
  분출물 분석은 직접 방출된 표적에 적용하고, 자연 유성이나 이후 일반 분열 조각의
  기본 데이터는 바꾸지 않는다. 부모 가치를 따르는 모듈 파편은 기존 계산을 따른다.
- 직접 방출된 유성은 다른 생성 효과처럼 메아리·사자자리의 첫 발동을 다시 유발하지
  않는다. 화이트홀·항성·블랙홀·거대 유성은 방출하지 않으며 중복 완료로 재분출하지 않는다.
- 파편 공간이 가득 차면 해당 방출을 건너뛰며 나중에 몰아서 재생하지 않는다.
  표시된 24·36·48개는 공간이 충분할 때의 수량이다. 분출량은 소환 시 연구 상태를 따른다.
- 미관측 만료 시 방출하지 않는다. 일시정지는 일정도 멈추고, 동작 강도 0에서도
  관측 결과와 수량은 유지한다. 회차 종료·리셋·불러오기는 본체와 남은 방출을 정리한다.

## 실제 별자리 기준과 저장

기준은 [IAU / Sky & Telescope 봉황자리 성도](https://iauarchive.eso.org/static/public/constellations/pdf/PHE.pdf),
좌표는 [Yale Bright Star Catalogue V/50](https://cdsarc.cds.unistra.fr/viz-bin/cat/V/50)의 J2000 값이다.
2026-09-15 VizieR에서 조회한 원본은 `build/white_hole/phoenix-bsc.tsv`에 보관하고
`tools/data/research-stars.json`에 아래 식별자와 적경·적위를 추가했다.

| 별 | 카탈로그 | J2000 적경 | J2000 적위 |
|---|---|---|---|
| α Phe (Ankaa) | HR 99 | 00h 26m 17.0s | −42° 18′ 22″ |
| β Phe | HR 322 | 01h 06m 05.0s | −46° 43′ 07″ |
| γ Phe | HR 429 | 01h 28m 21.9s | −43° 19′ 06″ |
| δ Phe | HR 440 | 01h 31m 15.1s | −49° 04′ 22″ |
| ε Phe | HR 25 | 00h 09m 24.7s | −45° 44′ 51″ |
| ζ Phe | HR 338 | 01h 08m 23.1s | −55° 14′ 45″ |

채택한 연결 도형 **기준 6별 = 게임 6별 = 연구 6개**다. α–β–γ, α–ε–β–ζ–δ–γ의
7개 선을 재현한다. PDF 벡터 선의 끝점도 대조했다. ν Phe는 β–γ 부근에 보이지만
선의 꼭짓점이 아니며, 성도의 다른 보조 별도 연구 수에 맞춰 제거한 구성별이 아니다.
공유 별·가상 표식은 없다. 기존 입체 투영·균일 축척을 사용하고 반전·개별 이동을 하지 않는다.

앵커 반경 1310·각도 −1.5, 도형 축척 130으로 궁수자리의 다음 바깥 구역에 놓았다.
이는 연구 성도상의 배치이며 실제 천구에서 두 별자리가 이웃이라는 뜻은 아니다.
목록은 봉황자리를 추가하고, 확장 후 행 간격만 줄여 모듈 버튼 위에서 모두 선택할 수 있게 했다.

저장 카탈로그는 7이다. 이전 소유권을 보존하며 화이트홀 연구를 자동 지급하지 않는다.
구형 저장에 없는 화이트홀 난수 스트림만 시드에서 시작하고 기존 스트림은 그대로 복원한다.
비행 중 화이트홀과 분출은 다른 일반 천체처럼 저장하지 않는다. 경제 시뮬레이터에도
화이트홀을 포함하며 변경 전 진단 체크포인트는 기존 분기 모드로 불러온다.

## 비교할 두 가지 외형

| 효과 | 표현 | 비교할 점 |
|---|---|---|
| 난류 원반형 — 기본 | 천천히 차등 회전하는 회청색·상아색 가스층, 작은 밝은 중심과 앞뒤로 겹치는 원반 | 넓은 발광 없이 빛·그늘과 겹침으로 깊이가 읽히는지 |
| 양극 제트형 | 같은 원반의 양쪽에 짧고 희미하게 이어지는 가느다란 가스 분출 | 원반보다 덜 두드러지면서 기본형과 구별되는지 |

[NASA 블랙홀 시각화](https://svs.gsfc.nasa.gov/13326/)의 빛나는 가스층,
밝기 비대칭과 겹쳐 보이는 원반을 시각적 참고로 삼았다. 화이트홀 외형을
예측하는 물리 시뮬레이션은 아니며, 방출 원반과 제트는 게임용 상상도다.
해당 자료의 이미지를 게임 텍스처로 사용하지 않는다.

가스는 셰이더의 여러 크기 난류와 전단 흐름으로 그린다. 부드러운 중심부에서
외곽의 낮은 밝기까지 변화시키고, 규칙적인 선·입자 배치를 없앤다.
가스 흐름은 첫 가스층 표현의 62% 속도이며, 촘촘한 밝은 실선 대신 넓고 부드러운
밀도층을 쓴다. 외곽 가스·원반 후광을 줄이고 중심에만 높은 밝기를 남긴다.
외형 비교용 고정 시제품은 원반 축을 약 ±14도 움직이고, 실제 관측 대상은
진행 방향을 유지하도록 ±3도로 줄인다. 시선에 대한 기울기는 서서히 변한다.
원반·후광·제트가 같은 축을 따르고, 내부 가스는 이 자세 변화와 별도로 순환한다.
모든 변화는 누적된 시각 시간만 사용하므로 일시정지·동작 강도 0에서 자세도 멈춘다.
배경 별빛에는 기존 블랙홀의 렌즈 셰이더를 재사용한다. 광학 노드는 하늘 직후,
유성·관측 장비보다 먼저 그려지므로 실제 표적의 관측 위치를 굴절시키지 않는다.
인스턴스마다 독립 재질이며, 보이는 활성 인스턴스당 화면 복사 1회가 필요하다.
숨김·화면 밖·동작 강도 0·완전 투명·만료 상태에서는 복사를 끈다.
전체 화면 플래시는 없고, 밝기 호흡은 최대 ±0.5%다.

## 게임에서 확인하기

- `Ctrl+Shift+W`: 커서의 월드 위치에 움직이는 관측 대상을 소환한다.
  카메라가 멀어져도 이동 속도와 관측 범위를 맞춘다. 해금 연구 없이 사용할 수 있다.
- `Ctrl+Shift+E`: 원반형과 제트형을 전환한다. 이미 표시된 화이트홀에도 적용된다.
- 동시에 최대 3개. 기본 수명 16초이며, 시작 0.6초 동안 부드럽게 나타난다.
  관측 완료 후 방출 전 연출은 별도 1초다. 회차 종료·새 런·리셋·불러오기 때 정리한다.
- 성도가 열린 일시정지 중에도 소환·전환 키는 처리하지만 시간은 흐르지 않는다.
- 동작 강도 0에서는 원반 방향·기울기와 가스 흐름을 멈추고 분출·별빛 굴절을 끈다.
  정적인 원반·중심·후광과 시간에 따른 소멸은 유지한다. 화면 번쩍임을 끄면 밝기 호흡도 끈다.

디버그 소환과 방출 방향 결정은 자연 출현 RNG를 소비하지 않으며, 생성된 유성의
후속 분열·모듈은 기존 규칙을 따른다. 자연 출현은 화이트홀 전용 스트림을 소비한다.

- `tests/white_hole_review.gd`: 실제 렌더러에서 두 효과, 제한된 그리기 범위,
  시간에 따른 자세·가스 변화와 시각 시간을 고정했을 때의 화면 안정성,

```powershell
& $godot --path . --script res://tests/white_hole_review.gd -- --animate
& $godot --path . --rendering-method gl_compatibility --rendering-driver opengl3 --script res://tests/white_hole_review.gd
& $godot --path . --script res://tests/white_hole_review.gd -- --observe
```

캡처는 `build/white_hole/<렌더러>/`에 저장한다. `--animate`는 두 효과를
동시에 보여주는 8초·24fps 비교용 PNG 시퀀스도 만든다. 실제 애니메이션 시간과
동일한 속도이며, 공유할 때는 두 천체 주변을 잘라 GIF로 변환한다. 테스트용 장면이며
사용자의 저장·설정을 변경하지 않는다.
`--observe`는 실제 고정 틱과 입력 버퍼로 이동 중인 대상을 수동 관측하고,
유성 방출·본체 소멸까지 8초·30fps로 기록한다. `observable/`에 PNG와 결과를 남긴다. `--observe --researched`는 봉황자리 효과를
적용한 48개 방출을 `researched/`에 기록한다. 다른 후기 자동화는 제외한 시각 비교용 상태다.
