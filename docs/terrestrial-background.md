# 확장 전 밤하늘

2026-09-17 사용자가 승인한 목업을 은하 기준 좌표계 연구 전 관측 배경에 적용한다.
그림 질감의 남청색 하늘·희미한 은하수와 평면적인 두 겹 능선을 조합하고 천문대를 제거했다.
확장 후 배경과 연구·저장·관측 범위·보상은 유지한다.

## 원본과 적용

- 파일: `resources/textures/terrestrial_sky.png`, 1672×941 PNG, 1,473,748바이트.
- SHA-256: `d69beffa3ea0407888ea8f06e1b108d3b7af1cffbf40ca7e02144be16c39417c`.
- 대화 내 이미지 생성 도구로 만든 승인 원본을 수정 없이 복사했다. 별도 Image API는
  호출하지 않았고 4K 재생성이나 후처리 확대도 하지 않았다. 4K 창에서는 원본을 확대해 표시한다.
- 원본 생성 프롬프트는 평면 목업의 낮은 능선 두 겹과 색·형태를 유지하면서 천문대와 빨간
  창을 없애고, 이전 일러스트의 남청색 하늘·별·희미한 대각선 은하수를 조합하도록 지정했다.
  입체적인 산·숲·건물은 가져오지 않고 유성·천체·UI도 배경에서 제외했다.

`scenes/terrestrial_background.tscn`이 텍스처·재질을 소유하고 메인 Starfield 아래에 배치한다.
Starfield는 현재 화면에 맞게 종횡비를 보존하여 덮고 4% 여유를 둔다. 이미지에 별과 산이
포함되어 있으므로 기존 정적 별·반짝임 별·산·천문대를 중복해서 그리지 않는다.
시작 시에도 반짝임 레이어의 초기 투명도를 동기화해 첫 화면에만 별이 겹치지 않게 한다.
리소스 없는 독립 Starfield는 기존 도형 렌더 비교용 절차적 경로를 유지한다.

## 밤에서 새벽으로

밤에는 원본 색을 그대로 표시한다. 관측 후반의 기존 `dawn_amount()`와 정산의 1.1초
`sunrise` 시계를 재사용하여 하늘빛이 서서히 따뜻해진다. 텍스처 위로 새 태양이나 지형을
덧그리지 않는다. 셰이더는 하단의 색 차이로 승인된 능선 경계를 따라 새벽빛을 적용하므로
산 실루엣은 어둡게 남는다. 이 경계 기준은 해당 원본에 맞춘 값이며 자산 교체 시 재검토한다.

게임 시간·관측과 보상은 연출 때문에 늘어나지 않는다. 일시정지·불러오기·즉시 계속하기·
동작 강도 0%는 기존 시계를 따른다. 확장 연구를 구매하면 이 Sprite를 숨기고 기존
깊은 우주 배경으로 바꾼다. 초기 슬롯이나 리셋에서는 그림 밤하늘로 돌아온다.

## 검증

`effect_feedback_test.gd`는 초기/확장 슬롯·리셋·정산 시계와 두 텍스처의 종횡비·
화면 덮기를 검사한다. 초기화 직후 반짝임 별이 숨겨져 있는지도 검사한다.
`deep_space_background_review.gd`는 밤/새벽/아침, 실제 일반·고속 유성과 한영 UI,
확장 전후 및 1440×900·2560×1080·3840×2160 창과 1.5배 화면 범위를 캡처한다.
고정 16:9 설정으로 창 크기와 렌더 크기는 다를 수 있으며 manifest에 둘 다 기록한다.
초기·리셋 배경과 한영 관측 영역은 같은 픽셀이어야 한다.
