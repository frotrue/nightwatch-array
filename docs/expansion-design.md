## 채택 범위와 검토

Pro 제안 D-001~D-014를 다음 구현 계약으로 채택한다. 기존 같은 하늘·성도,
좌클릭 유지, 관측/정산 리듬과 기존 95개 연구 경제를 유지한다. 모듈 14종,
특이 관측 3종, 계획 7개/관측장 18개를 연결한다. 새 기록 마감은 선택 가능한
완료 기록으로 보여 주며 기존 카탈로그 엔딩이나 게임 정지 조건에 연결하지 않는다.

- D-001~004: 후속 유료 연구 16개(기존 8+신규 8), 무료 시작/완료 기록 2개.
  세 기초 가지는 자유 순서다. 연구가 표적·계획·기본 모듈을 먼저 제공한다.
- D-005: 표본 8개로 해금된 미보유 설계안 최대 3개 중 선택, 12개로 지정 획득.
  중복·보유 후보 금지, 풀 소진 시 무차감, 미결 선택은 저장하고 재추첨 금지.
- D-006~007: 분광(본체→후방), 잔광(훑어 발견→복원), 쌍체(구성체 분담).

  동일 티켓을 재사용한다. 기존 연쇄·파편·훑기 소환·M31·일반 복원 잔광은 표본 없음.

## 연구와 계획

기존 모듈 가격은 focus/wide 120M, precision/record 180M, revisit 240M이다.
slot_3/4/5 가격은 240/360/480M, 선행은 각각 기초 1개/기초 2개/응용 2개 완료와
바로 전 슬롯이다. 이미 열린 자리는 계속 보존한다. revisit는 3자리부터 구매한다.

| 연구 | Data | 선행 | 결과 |
|---|---:|---|---|
| ext_protocol | 무료 | 첫 M31 또는 호환 모듈 보유 | 확장 접근 |
| ext_trace_study | 60M | protocol | 분광, trace_1, trail_integrator, 궤적 풀 |
| ext_sweep_study | 60M | protocol | 잔광, sweep_1, sweep_optics, 탐색 풀 |
| ext_link_study | 60M | protocol | 쌍체, link_1, relay_bus, 연계 풀 |
| ext_trace_advanced | 180M | trace_1 완료 | trace_2 |
| ext_sweep_advanced | 180M | sweep_1 완료 | sweep_2 |
| ext_link_advanced | 180M | link_1 완료 | link_2 |
| ext_synthesis | 240M | 기초 3개 완료 | 준비 노출 상한 1→2 |
| ext_combined_watch | 360M | 응용 3개+synthesis | integrated_1 |
| ext_record_complete | 무료 | integrated_1 완료 | 기록 마감 |

각 관측장은 준비 노출→현장 증거→M31 합성이다. 첫 M31은 최초 준비 노출로 인정한다.
완료 관측장·부분 증거는 회차 종료/계획 전환에도 보존한다. 계획 ID에는 `plan_`을 붙인다.

| 계획 | 관측장 |
|---|---|
| trace_1 | 단독 분광 / 사선 분광 |
| sweep_1 | 중앙 잔광 / 외곽 잔광 |
| link_1 | 가까운 쌍체 / 벌어지는 쌍체 |
| trace_2 | 평행 분광 2개 / 교차 분광 2개 / 시차 분광 2개 |
| sweep_2 | 좌우 잔광 / 상하 잔광 / 잔광과 일반 유성 |
| link_2 | 한쪽 수동·한쪽 자동 / 같은 표적 인계 / 자동 쌍체와 M31 병행 |
| integrated_1 | 분광+쌍체 / 잔광 2개+일반 유성 / M31+쌍체+잔광 순차 |

직접 담당은 수동 작업량 25%, 자동 담당은 자동 작업량 75%, 인계는 둘 다 25%다.
병행은 쌍체 자동 진행 중 M31 진행 25%다. 기초 계획 각각 최초 완료 시 표본 6개.
관측 실패로 기존 증거를 지우지 않는다. 필수 계획에 표본 모듈을 요구하지 않는다.

## 사건과 저장 불변식

첫 기회는 계획 진입 후 활성 관측 8초, 이후 32~44초 간격을 독립 RNG로 미리 정한다.
필요한 계획 사건을 우선하고, 자유 관측은 해금 종류의 비복원 순환이다. 예고/수명/2초
여유가 남지 않으면 다음 회차로 이월한다. 모든 시계는 모달·정산 중 정지한다.
전체 표적 예산 32에서 중요 사건 1, 확장 구성체 최대 3을 예약하고 기존 표적은 지우지 않는다.
분광·쌍체는 예고 1.5초/체류 12초, 잔광은 통과 3초/잔광 12초다.
작업량은 분광 단계당 1.8초, 쌍체 구성체당 2.2초, 잔광 2.4초다.
기본 Data는 분광/잔광 56, 쌍체 구성체당 42다.

`누적 표본 ≤ 고유 자격 사건 완료 수 × 2 + 최초 기초 계획 보상 18`을 유지한다.
미결 후보·차감·시드·일련번호와 사건 티켓·구성체·기여량을 저장한다. 계획 재시도와
새로고침은 이미 지급한 보상을 반복하지 않는다. 전체 표본 모듈 소진 후 표본 지급을 멈춘다.
v1의 M31 부분 진행 적분은 당시 장착 배율로 초기화한다. 새 계획은 보유 수로 추정하지 않는다.
알 수 없는 deep_sky 버전은 초기화 저장으로 덮어쓰지 않는다.
