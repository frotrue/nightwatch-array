# 특수 유성과 모듈 뽑기

2026-09-08 사용자 승인: 기존 계획 7개/관측장 18개와 노출 준비·증거·합성,
별도 분석 화면, 후보 선택과 지정 획득을 제거한다. 같은 하늘에서 특수 유성을
관측해 표본을 얻고, 모듈 편성창에서 임의 모듈 하나를 뽑는다.
중복 보유·중복 장착을 허용하며, 같은 모듈의 증감분은 합산한다.
기존 별자리 형상과 연구별 18개를 보존하고 선행 연구+데이터로 진행한다.
[대체된 설계 원문](history/expansion-plans-2026-09-07.md)은 별도 보존한다.

## 관측과 획득

- M31 첫 관측이 무료 프로토콜을 연다. 이후 특수 유성 한 종류가 자연 출현한다.
  일반 유성처럼 커서를 맞추고 좌클릭을 유지하거나 접시로 자동 관측한다.
- 수동·자동 모두 완료당 표본 2개. 표본 회수 연구 후 3개다. 데이터도 같은 회차에 합산한다.
- 편성창에서 표본 8개를 쓰면 여섯 모듈 중 하나가 같은 확률(각 1/6)로 나온다.
  제작 효율화 연구 후 6개다. 기초 연구 가지나 기존 보유 수는 뽑기 풀을 바꾸지 않는다.
- 동일 모듈도 계속 획득한다. 결과는 소유 수량을 늘리고 자동 장착하지 않는다.
  장착 자리와 연구에 표본 소모·추첨 결과·관측 횟수를 요구하지 않는다.
- 첫 생성 기회는 활성 관측 8초 후, 이후 32~44초 간격이다. 발견 연구 후 간격 ×0.8.
  남은 회차 22초 미만 또는 큰개자리 중요 사건과 충돌할 때는 다음 안전한 기회로 미룬다.
- 예고 1.5초, 관측 가능 12초, 기본 관측 시간 2.2초. 데이터 기초값 56.
  기존 추적 품질·분석 속도·자동 보상 계수를 적용한다. 일반 연쇄와 파편을 생성하지 않는다.
- 총 표적 32개 중 중요 사건 자리 1개를 보존하고, 확장 표적/복원 잔광은 최대 3개다.
  특수 유성과 복원 잔광이 남아 있으면 다음 자연 특수 유성을 생성하지 않는다.
  정산·성도·편성·설정 중 시계가 멈춘다.

## 연구

기존 모듈 5종과 자리 가격은 유지한다. 셋째 자리는 궤적 기초 연구,
넷째 자리는 셋째 자리+탐색·연계 기초 연구, 다섯째 자리는 넷째 자리+지속 관측이 선행한다.
자리 가격은 각각 240/360/480M 데이터이며 이미 열린 자리는 보존한다.

| ext_trace_study | 60M | protocol | 궤적 적분 모듈 획득 |
| ext_sweep_study | 60M | protocol | 훑기 광학 모듈 획득 |
| ext_link_study | 60M | protocol | 연계 버스 모듈 획득 |

### 성도에 이어지는 연구별

| 별자리 | 연구별 | 배치한 연구 |
|---|---:|---|
| 페가수스자리 | 5 | 시작 프로토콜·표본 회수·지속 관측·다섯째 자리·제작 효율화 |
| 백조자리 | 5 | 궤적 연구·집중 관측·정밀 추적·추적 정밀화·셋째 자리 |
| 세페우스자리 | 5 | 연계 연구·심층 기록·재관측·접시 정밀화·넷째 자리 |
| 독수리자리 | 3 | 훑기 연구·광역 관측·광역 탐색 |

기존 안드로메다자리의 알페라츠가 페가수스 사각형의 한 꼭짓점이다. 연구를 중복 배치하거나
기존 좌표를 옮기지 않는다. 새 연구별 18개를 합치면 성도 진행 계기는 113개다.
그림의 연결선은 별자리 형상이며 선행 조건은 별을 선택한 정보창에서 설명한다.
회전·확대, 지평선 가림, 별을 길게 눌러 설치, 밝아지는 별과 선은 기존 성도와 같다.
편성창에서 돌아오면 이전 성도 방향과 확대율을 유지한다. 예전 저장의 연구·모듈 ID는 유지한다.

구성원과 베이어 표기는 IAU의 [백조자리](https://iauarchive.eso.org/static/public/constellations/pdf/CYG.pdf),
[세페우스자리](https://iauarchive.eso.org/static/public/constellations/pdf/CEP.pdf),
[독수리자리](https://iauarchive.eso.org/static/public/constellations/pdf/AQL.pdf),
[페가수스자리](https://iauarchive.eso.org/static/public/constellations/pdf/PEG.pdf) 성도를 참고했다.
배치는 게임용으로 단순화한 형상이며 적경·적위 투영이나 정밀 위치·등급 계측도가 아니다.

M31 수입과 다음 대기 배율은 노출 진행량으로 적분한다. 절반만 record는 ×1.25,
절반만 revisit는 ×0.8이다. 진행 중 장착 교체는 무료이며, 이미 시작된 대기는 불변이다.

## 중복 편성

소유 수량 이내에서 같은 모듈을 여러 자리에 장착한다. 같은 ID의 배율은
`1 + (한 개 배율 − 1) × 장착 수량`으로 합산하고 서로 다른 ID는 기존처럼 곱한다.
예를 들어 +50% 두 개는 ×2.0, −15% 두 개는 ×0.7이다.
음수 배율이 생기지 않도록 개별 배율 하한은 ×0.1이다. 신규 수동 계수는 최종
×0.25~2.5, 신규 접시 계수는 ×0.25~2.5로 기존 상한을 유지한다.
복원 잔광은 동시 하나·8초를 유지하며 장착 1개당 회수 데이터 +50%다.
셔터의 5초 창은 갱신하고 강도와 M31 대기 페널티를 합산한다.

## 저장과 거래

외부 저장 버전은 1, `deep_sky`는 3이다. 기존 연구 ID, 소유 모듈, 열린 자리,
표본 잔액과 M31 부분 관측·가중 보상·대기를 보존한다. 수량 필드가 없는 모듈은 1개다.
동일 모듈의 중복 자리도 해당 소유 수량까지만 복원한다.
v2의 유료 미선택 후보가 남아 있으면 8표본을 한 번 환불한다. 이미 얻은 모듈은 유지한다.
구형 계획 기록은 새 선행 조건으로 사용하지 않는다. 진행 중인 구형 사건은 사건당
하나의 특수 유성으로 변환하며 정규화된 관측 진행률과 기존 지급 여부를 보존하고
새 관측 시간을 제공한다. 모듈로 생성된 복원 잔광은 그대로 복원한다.

추첨 시드·순번·마지막 결과·소유 수량과 차감을 함께 저장한 뒤 결과를 표시한다.
활성 저장 슬롯의 쓰기가 실패하면 전부 복구한다. 결과만 공개하고 표본 차감을
누락하거나 실패 후 다른 결과로 바뀌지 않는다. 이미 완료한 표적은 데이터와 표본을
중복 지급하지 않는다. 알 수 없는 저장 버전은 덮어쓰지 않는다.

## 검증 범위

상태 검사는 선행 관계만으로 모든 연구에 도달하는지, 복원 추첨, 중복 보유/장착,
가산 효과와 잘못된 저장의 정리를 확인한다. 실제 게임 통합 검사는 수동·접시 관측,
표본 보상, 쓰기 실패 복구, 활성 표적과 M31 적분 저장을 확인한다.
편성 UI 검사는 실제 버튼·수량·언어·성도 복귀를 확인한다. 화면 캡처는 합성 상태이며
사람의 재미나 목표 완주 시간을 입증하지 않는다.
