# 특수 유성과 모듈 뽑기

2026-09-08 사용자 승인: 기존 계획 7개/관측장 18개와 노출 준비·증거·합성,
별도 분석 화면, 후보 선택과 지정 획득을 제거한다. 같은 하늘에서 특수 유성을
관측해 표본을 얻고, 별도 뽑기창에서 임의 모듈 하나를 뽑는다.
중복 보유·중복 장착을 허용하며, 같은 모듈의 증감분은 합산한다.
후속 사용자 승인에 따라 바깥 별자리 11개·연구별 55개로 확장한다. M31 전용 연구 5개를 보류하고 나머지는 선행 연구+데이터로 진행한다.
[대체된 설계 원문](history/expansion-plans-2026-09-07.md)은 별도 보존한다.

## 관측과 획득

- 은하 기준 좌표계 연구가 무료 프로토콜을 연다. 이후 특수 유성 한 종류가 자연 출현한다.
  일반 유성처럼 커서를 맞추고 좌클릭을 유지하거나 접시로 자동 관측한다.
- 수동·자동 모두 완료당 표본 2개. 표본 회수 연구 후 3개다. 데이터도 같은 회차에 합산한다.
- 뽑기창에서 표본 8개를 쓰면 8종 중 하나가 같은 확률(각 1/8)로 나온다.
  제작 효율화 연구 후 6개다. 기초 연구 가지나 기존 보유 수는 뽑기 풀을 바꾸지 않는다.
- 동일 모듈도 계속 획득한다. 결과는 소유 수량을 늘리고 자동 장착하지 않는다.
  장착 자리와 연구에 표본 소모·추첨 결과·관측 횟수를 요구하지 않는다.
- 첫 생성 기회는 활성 관측 8초 후, 이후 32~44초 간격이다. 발견 연구 후 간격 ×0.8.
  남은 회차 22초 미만 또는 큰개자리 중요 사건과 충돌할 때는 다음 안전한 기회로 미룬다.
- 예고 1.5초, 관측 가능 12초, 기본 관측 시간 2.2초. 데이터 기초값 56.
  기존 추적 품질·분석 속도·자동 보상 계수를 적용한다. 일반 연쇄와 파편을 생성하지 않는다.
- 폭증 방지용 전체 안전 상한 65개 중 중요 사건 1자리, 특수 유성 최대 3자리를 보존한다. 블랙홀 전용 1자리를 추가해 기존 공간을 유지한다.
  특수 유성이 남아 있으면 다음 자연 특수 유성을 생성하지 않는다.
  정산·성도·편성·설정 중 시계가 멈춘다.

## 첫 모듈 안내

2026-09-14 승인에 따라 은하 기준 좌표계 해금과 은하 전환 연출 뒤 첫 사용 안내를 시작한다.
첫 뽑기용 표본 8개를 저장 슬롯마다 한 번 지급한다. 뽑기창 열기 → 뽑기 → 결과 효과 확인 →
강조된 빈 자리 장착 순서로 실제 버튼을 누른다. 이때 다른 조작은 차단하며 Enter/Space로도
진행할 수 있다. 결과 연출은 건너뛰거나 동작 줄이기 설정을 따른다. 장착 후에는 기존 편성창에서
모듈 교체·해제·추가 뽑기를 자유롭게 한다. 후속 연구나 특정 모듈 수집을 강제하지 않는다.

안내 중에도 메뉴 뒤로 키(기본 Esc)로 설정과 저장 슬롯을 열 수 있다. 진행은 기존 저장의
선택 필드 `module_intro_stage`와 `module_intro_id`로 보존한다. 첫 뽑기·장착은 기존 저장
트랜잭션에 포함되어 저장 실패 시 표본·소유·안내 단계가 함께 복원된다. 결과를 본 뒤 종료하면
다음 로드에서 같은 모듈의 결과 확인부터 이어진다. 추첨 이력이나 보유 모듈이 있는 구형 저장은
안내 완료로 이관하며, 아직 사용하지 않은 구형 저장은 한 번 지급 후 안내한다.

경제 시뮬레이터는 UI 안내만 끈다. 실제 지급은 동일하게 반영하며 구매가 일어난 회차의
`samples`에 포함하고 `sample_bonus`로 해금 지급분을 구분한다.

Ctrl+Shift+T는 해금 여부와 관계없이 첫 모듈 안내를 미리 보여 준다. 임시 모듈·표본 상태를
사용하며 실제 저장과 보유 기록은 바꾸지 않는다. 장착 완료 또는 Esc / 같은 단축키로 종료하면
이전 화면과 일시정지 상태로 돌아간다. 시작 슬롯 선택·다른 튜토리얼·설정·정산·은하 전환·뽑기 연출 중에는 시작하지 않는다.

## 연구

모듈 지원은 페가수스·도마뱀자리의 10개 연구에 모은다. 나머지 7개 별자리의
32개 연구는 장착 없이 관측을 성장시킨다. [별자리별 연구·가격·선행·효과](outer-constellations.md)가
현재 상세 기준이다. 모듈 자체를 직접 주던 연구 8개는 영구 관측 성장으로 바꾼다. 사용자가 승인한 대로
2026-09-10 M31 보류 결정으로 활성 모듈은 8종이며, 전용 4종의 기존 수량은 보존한다.

페가수스의 셋째 자리에는 프로토콜, 넷째 자리에는 셋째 자리, 다섯째 자리에는 넷째 자리가 필요하다.
가격은 45/60/80M 데이터다. 제작 효율화는 다섯째 자리와 특수 유성 지속 관측 이후 무료로 열린다.
도마뱀자리는 특수 유성 관측 시간 ×0.75, 출현 간격 ×0.8, 접시 관측 속도 ×1.25,
완료 표본 2→3, 관측 가능 시간 +4초를 맡는다.

### 성도와 뽑기창

기존 안드로메다자리의 알페라츠가 페가수스 사각형의 한 꼭짓점이다. 연구를 중복 배치하거나
기존 좌표를 옮기지 않는다. 바깥 연구별 55개를 합치면 성도 진행 계기는 150개다.
그림의 연결선은 별자리 형상이며 선행 조건은 별을 선택한 정보창에서 설명한다.
회전·확대, 지평선 가림, 별을 길게 눌러 설치, 밝아지는 별과 선은 기존 성도와 같다.
편성창·뽑기창에서 돌아오면 이전 성도 방향과 확대율을 유지한다. 예전 저장의 활성 연구와 모든 모듈 소유 기록은 유지한다.

구성원과 베이어 표기는 IAU의 [백조자리](https://iauarchive.eso.org/static/public/constellations/pdf/CYG.pdf),
[세페우스자리](https://iauarchive.eso.org/static/public/constellations/pdf/CEP.pdf),
[독수리자리](https://iauarchive.eso.org/static/public/constellations/pdf/AQL.pdf),
[페가수스자리](https://iauarchive.eso.org/static/public/constellations/pdf/PEG.pdf) 성도를 참고했다.
도형 내부는 [J2000 좌표의 투영](constellation-geometry.md)을 따른다. 도형 사이 배치와 별 밝기는 연구 UI 표현이며 전체 천구 계측도는 아니다.

과충전은 분열·훑기·공명 유성의 완료도 세고, 동일 완료를 중복 집계하지 않는다.
성도·편성·설정에서는 시간이 멈추고 저장 시 남은 시간·충전을 보존한다. 다음 회차와
과충전 장착 변경에서는 초기화한다. 커서의 작은 충전 막대와 발동 시 확대·색으로 표시한다.

2026-09-10 삭제한 궤적 적분기·연계 버스·장기선·이중 처리기·잔광 기록고의 효과는
다른 이름으로 남기지 않는다. 구형 소유·장착은 제거하고 이전 잔광도 복원하지 않는다.

분열 관측은 기존 `focus` ID·소유 수량·장착 자리를 보존하고 수동 속도 +80%를 대체한다.
원본 위치에서 같은 색의 작은 유성 둘이 서로 다른 방향으로 날아가며, 각각 원본 기본 데이터의
25%를 가진다. 품질·자동 관측·연구 보상 배율은 작은 유성을 관측할 때 평소처럼 적용한다.
작은 유성은 2.9초 동안 남고 재분열·쌍둥이/사자 유성 연쇄의 원인이 되지 않는다.
기존 파편형·발광 유성·거대 유성은 이 효과의 원본에서 제외하며 파편 연구는 유지한다.
장착 1개당 확률 +30%p, 최대 100%이다. 파편 생성은 자연 유성의 연구별 동시
관측 한도에 막히지 않으며 공통 22개 제한도 적용하지 않는다. 살아 있는 파편은
새 자연 등장을 조절할 때에는 기존처럼 센다. 대기권·파편 합계
54개의 최종 안전 상한과 심층/거대 표적 예약은 유지한다. 안전 상한까지 두 자리가
없거나 관측 시간이 끝났으면 생성하지 않는다.

## 중복 편성

보관함은 3열과 기존 스크롤을 유지한다. 각 항목의 관측 기호·이름·수량은
서로 겹치지 않는 세로 영역을 쓰며 영문 코드는 선택 상세에만 표시한다.
요약은 실제 수치 변화와 조건부 효과 종류 수를 표시하고 전체 수치·조작법은 필요할 때 펼친다.
키보드로 연 설명창은 선택한 항목이나 장착 자리에
고정하고 스크롤 뒤 위치를 갱신한다. 포인터로 항목을 가리키거나 움직이면 마우스를 따라가며,
화면 가장자리에서는 설명창 전체가 보이도록 위치를 보정한다.

소유 수량 이내에서 같은 모듈을 여러 자리에 장착한다. 같은 ID의 배율은
`1 + (한 개 배율 − 1) × 장착 수량`으로 합산하고 서로 다른 ID는 기존처럼 곱한다.
예를 들어 +50% 두 개는 ×2.0, −15% 두 개는 ×0.7이다.
음수 배율이 생기지 않도록 개별 배율 하한은 ×0.1이다. 신규 수동 계수는 최종
×0.25~2.5로 기존 상한을 유지한다. 과충전은 이 계수 밖에서 적용한다.
광역 모듈은 장착 1개당 추가 표적 +2이며, 기존 다중 관측 연구의 무제한 표적은 유지한다.
선형 관측은 복사본마다 너비 배율 +3(×4→×7), 감속 관측은 개당 −30%p(최대 90% 감속)다.
과충전은 속도 +100%p·반경 +50%p를 합산하고 발동 조건 30회·9초는 유지한다.

## 저장과 거래

외부 저장 버전은 1, `deep_sky`는 4이다. 기존 연구 ID, 유지되는 모듈의 소유 수량, 열린 자리,
표본 잔액을 보존한다. M31의 과거 진행은 실행되지 않는 별도 기록에 보존한다. 수량 필드가 없는 모듈은 1개다.
동일 모듈의 중복 자리도 해당 소유 수량까지만 복원한다.
v2의 유료 미선택 후보가 남아 있으면 8표본을 한 번 환불한다. 이 환불은 후보의 현재 존재 여부와 무관하며, 삭제된 모듈의 소유를 복구하지 않는다.
구형 계획 기록은 새 선행 조건으로 사용하지 않는다. 진행 중인 구형 사건은 사건당
하나의 특수 유성으로 변환하며 정규화된 관측 진행률과 기존 지급 여부를 보존하고
새 관측 시간을 제공한다. 삭제된 모듈의 복원 잔광은 제거한다.

추첨 시드·순번·마지막 결과·소유 수량과 차감을 함께 저장한 뒤 결과를 표시한다.
활성 저장 슬롯의 쓰기가 실패하면 전부 복구한다. 결과만 공개하고 표본 차감을
누락하거나 실패 후 다른 결과로 바뀌지 않는다. 이미 완료한 표적은 데이터와 표본을
중복 지급하지 않는다. 알 수 없는 저장 버전은 덮어쓰지 않는다.

## 검증 범위

상태 검사는 선행 관계만으로 모든 연구에 도달하는지, 복원 추첨, 중복 보유/장착,
가산 효과와 잘못된 저장의 정리를 확인한다. 실제 게임 통합 검사는 수동·접시 관측,
표본 보상, 쓰기 실패 복구, 활성 특수 유성 저장과 폐지 콘텐츠 재활성화 방지을 확인한다.
편성 UI 검사는 실제 버튼·수량·언어·성도 복귀를 확인한다. 화면 캡처는 합성 상태이며
사람의 재미나 목표 완주 시간을 입증하지 않는다.

### 결과 공개 연출

성도 왼쪽의 모듈 뽑기와 편성창의 연결 버튼은 같은 별도 뽑기창을 연다.
중앙의 표본 판독 링과 신호 정렬은 1.8초간 움직이고 실제 획득 모듈의 이름·효과·보유 수량을 공개한다.
연출 중 추가 뽑기는 막고 건너뛰기를 제공한다. 모션 강도 0에서는 즉시 결과를 보여 준다.
결제·모듈 획득·RNG·최근 결과를 저장한 다음 연출하므로 창 닫기·저장 복원·건너뛰기는 재추첨하지 않는다.
저장에 실패하면 결제와 획득을 복구하고 새 결과 연출을 시작하지 않는다.
뽑기창에서 편성창으로 이동해 직접 장착하며, Esc로 성도로 돌아간다.

## 디버그 모듈 뽑기

Ctrl+Shift+G는 해금·표본 조건 없이 활성 8종 중 하나를 즉시 보유한다.
중복은 수량으로 쌓이고 자동 장착하지 않는다. 일반 뽑기의 추첨 순번·표본은 유지한다.
활성 슬롯 저장 실패 시 지급을 취소하며, 일반 뽑기 연출 중에는 실행하지 않는다.
뽑기창에서는 결과를 즉시 표시하고, 그 밖에서는 획득 알림을 표시한다.
