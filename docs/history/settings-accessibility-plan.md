# 설정·조작·접근성 개선 계획 v2.1

> 완료된 개편의 승인·설계 기록이다. 아래 구현 지시는 당시 작업 범위이며,
> 현재 항목과 동작은 [설정 참조](../settings.md)를 따른다.

2026-09-04 Agent Room `AM-EKNS`에서 Claude, Codex, Lumen이 각자 제안하고
상호 검토한 v1.3을 기반으로 한다. 이후 짧은 인크리멘털 12종과 장기형 15종을
추가 조사해 v2.0 설정 콘솔을 확정했다. v2.1에서는 포커스에 따라 프레임 제한을
자동으로 바꾸던 정책을 제거했다. 조사표와 출처는
[settings-reference-study.md](settings-reference-study.md)에 있다. 이번 작업은 게임
규칙이나 기본 난이도를 바꾸지 않고 실제 편의·접근성·성능 표면만 확장한다.

## 확정 범위

1. `GameSettings`가 언어, 튜토리얼 상태, 성도 회전과 함께 전체 음량, 음소거,
   비활성 창 음소거, 전체 화면, VSync, FPS 상한, 카메라 impact 강도, 화면 섬광,
   사용자 키 설정을 v3 스키마로 저장한다.
2. `project.godot`의 `nw_*` InputMap을 단일 기본값으로 삼는다. 관측 LMB와 접시 RMB는 이번 버전에서 고정한다. 성도, 메뉴/뒤로 보조키, 정산 계속 보조키, 전체 화면은 바꿀 수 있다.
3. 일시정지 중에도 동작하는 `GameInputRouter`가 모달 우선순위를 한곳에서 판정한다. 연구 성도와 엔딩 연출처럼 기존에 먼저 입력을 받아야 하는 화면은 첫 처리권을 유지한다.
4. 설정은 `일반 / 소리 / 화면 / 접근성 / 조작 / 저장` 좌측 레일과 한 개의 내용
   영역을 가진 고정 셸이다. 기존 아코디언과 중첩 조작 오버레이는 사용하지 않는다.
   조작 페이지는 전체 조작과 연구 선행 조건을 항상 보여 준다.
5. 설정, 조작키, 시작 슬롯, 튜토리얼의 welcome/complete 화면은 키보드 포커스와 명확한 복귀 경로를 제공한다. 실제 플레이 중 비모달 튜토리얼은 포커스를 빼앗지 않는다.
6. 키 입력 대기는 GUI보다 먼저 후보를 소비한다. `Esc`는 취소, echo와 modifier-only는 무시, 후보의 key-up까지 소비한다. 컨텍스트가 겹치는 충돌과 GUI/디버그가 선점하는 예약키는 저장 전에 거부한다.
7. 화면에 표시되는 성도 키 안내는 저장된 바인딩을 즉시 반영한다.
8. 메뉴의 선택 보조키는 다른 사용자 지정값을 잃지 않고 그 슬롯만 제거할 수 있다.
9. HUD 버튼과 `Esc`는 같은 셸을 열며, 셸은 현재 런 위에서 즉시 일시정지한다.
   헤더가 pause를 명시하고 어느 페이지에서든 `Esc` 한 번으로 게임에 복귀한다.
   닫을 때 정산·튜토리얼 등 기존 pause 소유권은 해제하지 않는다.
10. `카메라 impact 강도`는 kick과 shake만 줄인다. 값을 낮추면 진행 중인 효과도
    즉시 같은 비율로 줄고 0%에서는 둘 다 완전히 멈춘다. 화면 섬광을 꺼도
    링·입자·배너·음향은 중요한 관측을 계속 구분한다.
11. 설정 전용 보조문구는 1152×648 내부 렌더 기준 12px 이상, 상호작용 문구는
    14px 이상을 유지한다. 저우선순위 정보도 `INK_MID` 이상의 대비를 쓰며,
    슬라이더 포커스는 색뿐 아니라 더 굵은 레일과 외곽선으로 구분한다.

## 고정 안전장치

| 동작 | 고정 입력 | 변경 입력 | 활성 컨텍스트 |
|---|---|---|---|
| 관측/추적 | LMB | 없음 | 관측 |
| 접시 이동 | RMB | 없음 | 관측 |
| 연구 성도 | 없음 | 기본 `U` | 관측, 성도 |
| 메뉴/뒤로 | `Esc` | 선택 보조키 | 관측, 성도, 설정, 대화상자, 정산, 엔딩 |
| 정산 계속 | `Enter`, `Space` | 기본 `U` | 정산 |
| 전체 화면 | 없음 | 기본 `F11` | 전역 |

성도와 정산의 `U`는 활성 컨텍스트가 겹치지 않으므로 허용한다. 전체 화면은 전역이라 다른 변경 입력과 겹칠 수 없다. 기본값 복원은 `nw_*`만 건드리고 다른 InputMap 액션은 보존한다.

## 회의에서 수정된 안

- 전역 충돌 금지안은 컨텍스트 기반 충돌로 바꿨다. 그래야 익숙한 `U`를 성도와 정산 양쪽에서 안전하게 유지할 수 있다.
- `F11` 고정안은 전체 화면도 변경 가능하게 바꿨다. 대신 `Esc`, `Enter`, `Space`만 탈출/진행 안전키로 고정했다.
- 모든 튜토리얼 단계가 포커스를 잡는 안은 폐기했다. 일시정지 모달 단계만 포커스를 잡고 실제 조작 단계는 플레이 입력을 보존한다.
- 단순 전역 키 처리만으로는 일시정지 정산 입력이 죽고 성도 첫 처리권과 충돌했다. 항상 처리되는 라우터와 화면별 첫 처리권을 결합했다.
- 저장은 되지만 실제로 GUI나 디버그가 먼저 소비하는 키가 생길 수 있다는 검토 결과에 따라 `F9`, 현행 Ctrl+Shift 디버그 조합, Tab/방향/Home/End/Page 키를 예약했다.
- 정산 위에서 튜토리얼을 재생하면 pause 소유권이 꼬이는 교착을 발견해 버튼 비활성화와 게임 로직 가드를 함께 둔다.

## 검증 기준

- 실제 `Viewport.push_input` 경로로 paused 정산의 `U`/`Enter`/`Space`, 성도 `Esc` 우선 처리, 다음 `Esc` 설정 열기, 전체 화면, 모달 차단을 검증한다.
- 재지정 후보 press와 matching release가 다른 동작으로 새지 않고, 변경 뒤 옛 키는 멈추며 새 키만 동작해야 한다.
- 설정 테스트는 주입한 임시 경로만 사용하고, 오디오·화면·InputMap 상태를 스냅샷 후 복구한다.
- 영어와 한국어 모두 1152×648에서 설정/조작 화면을 렌더해 잘림과 포커스 표시를 확인한다.
- 여섯 페이지가 한 셸에서 상호 배타적으로 열리고 마지막 페이지·페이지별 포커스·
  설정 전 포커스가 복구되는지 확인한다.
- 비활성 창 음소거는 사용자 mute 값을 바꾸지 않아야 한다. FPS 상한은 포커스
  전환과 무관하게 사용자가 고른 값을 유지해야 한다.
- 접근성 테스트는 camera impact를 낮출 때 진행 중인 kick/shake도 즉시 줄어드는지,
  0%에서 둘 다 사라지는지, flash off가 full-screen flash만 없애고 링·입자를
  남기는지 검사한다.
- 창 모드 전용 테스트는 실제 `Engine.max_fps`, `DisplayServer` VSync, 시작 포커스
  상태를 확인한다. 화면 캡처는 한·영 여섯 페이지에서 연속 두 프레임의 픽셀
  데이터가 같을 때만 기록한다.
- 전체 검증 게이트와 Windows export가 통과해야 완료로 본다.

## 후속 접근성 단계

UI 배율, 고대비/색각 프리셋, 파티클 밀도, 성도 pullback을 포함하는 전역 모션 감소,
포인터 대체 조작, 완전한 컨트롤러 지원은 후속 범위다. 특히 판정 반경이나 hold
규칙을 바꾸는 옵션은 현재 게임 설계 계약에 영향을 주므로 이 문서만으로 도입하지
않는다. 숫자 표기, 음악 슬라이더, cloud/export는 현재 게임에 실체가 없어 이번
버전에서 의도적으로 제외했다.
