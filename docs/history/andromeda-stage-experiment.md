# 폐기한 안드로메다 별도 스테이지 실험

2026-09-05 후속 사용자 승인: 은하별 관측 스테이지에서 기존 성장 위에 연구와
기능을 계속 쌓는 방향으로 전환한다. 첫 무대는 LMC 대신 **안드로메다은하(M31)**다.
유성 하늘과 분리된 새 관측 화면을 사용하며 별도 내부 지도는 만들지 않는다.
장비 계승 절차·별도 계승 메뉴·초기화는 없다. 기존 별자리 연구는 유지한다.
첫 구현은 은하 지도에서 안드로메다 관측에 진입해 기존 데이터로 **집중 관측 /
광역 관측** 모듈을 구매하고 슬롯 하나에 편성하는 구간이다. 모듈 미장착으로도
관측과 수입이 가능하고, 구매는 영구적이며 연구 화면에서 편성을 무료로 바꾼다.
첫 구매는 자동 장착한다. 기존 관측 범위·수동 분석 속도와 접시의 기본 표적
자동 관측을 사용한다. 천체별 모듈 장착을 강제하지 않는다.

첫 구간의 조정용 수치: 두 모듈 각각 1억 2천만 데이터. 집중은 한 표적 수동
속도 1.8배, 광역은 반경 +65% 및 최대 3개 표적을 각각 기본 속도 75%로 관측한다.
청색 별 무리, G1 구상성단, NGC 206 별 구름을 같은 화면에 두어 효과를 비교한다.
이 수치는 첫 구현의 조정 기준이며 장기 경제의 승인값이 아니다.
안드로메다에서도 기존 연구로 얻은 회차 길이를 사용한다. 회차가 끝나면 모듈
화면에서 정비하고 다음 관측을 시작한다. 관측 진행·구매·편성·기록은 슬롯에 저장한다.

2026-09-06 사용자 수정 승인: 아래 장비 작업대 방향은 분위기가 맞지 않아 폐기한다.
DEFRAG를 주 시각 레퍼런스로 삼아 기존 별하늘·별자리의 어두운 바탕, 얇은 선과
작은 기호 안에서 모듈을 편성한다. 대형 관측기·금속 카트리지·불투명한 3열 패널을
없애고 선택 상세와 넓은 시험 하늘을 연결한다. DEFRAG의 격자·원색·OS 창은
그대로 복제하지 않고 기존 관측소 색과 천체 표현을 유지한다.
앞서 제안한 모듈 조합을 구현하는 첫 범위로 슬롯을 두 개로 늘려 집중·광역을
함께 편성할 수 있게 한다. 중복 장착은 금지한다. 속도·반경 배율은 곱하고 동시
관측 수는 최댓값을 사용한다(집중+광역: 속도 ×1.35, 반경 ×1.65, 최대 3개).
종류와 가격은 유지한다. 선택한 슬롯에 반영한 조합과 현재 편성을 무료 시험으로
전환해 비교한다. 선택/시험은 구매·장착과 구분하고 실제 관측·저장을 바꾸지 않는다.
기존 단일 슬롯 저장은 첫 슬롯으로 복원한다. 새 슬롯은 비어 있으며 구매를 지급하지 않는다.

2026-09-05 이전 작업대 구현(위 승인으로 대체): 설정 목록처럼 보이던 모듈 창을 Steam 장비 편성
게임 최소 10종 조사에 근거해 재디자인하고 기능을 추가한다. 12종 조사 기록은
[모듈 작업대 레퍼런스](../module-workbench-reference-study.md)에 남긴다.
모듈 보관함의 카드, 중앙 광학 관측기의 소켓, 선택 모듈의 시험 시야를 한 화면에
둔다. 선택은 장착과 구별되며 미보유 모듈도 무료로 시험할 수 있다. 보유 모듈은
소켓으로 드래그하거나 버튼으로 장착한다. 구매 후 장착 버튼은 가격을 지불하고
선택한 모듈을 실제로 장착한다. 단일 슬롯과 두 모듈의 가격·효과는 유지한다.
시험 관측은 실제 표적 선택·속도 계산을 공유하지만 데이터·기록·회차·저장을 바꾸지
않는다. 장착 중과 선택 모듈의 성능을 비교하고, 인게임에서는 카트리지 형상·관측
연결선·진행률·완료 표식으로 실제 기능을 드러낸다.

2026-09-05 후속 수정 승인: 기존 은하 연구 화면을 **은하 선택 화면**으로 교체한다.
국부은하군 연구 12개와 장식 표식 17개, 연결선·궤도·설치 개수·연구 비용·정보창은
더 이상 이 화면에 표시하거나 조작하지 않는다. 은하 선택은 연구 구매가 아니며
데이터를 소모하지 않는다. 현재 실제로 진입할 수 있는 목적지는 안드로메다 하나다.
목적지 이름·관측 가능 상태·진입 동작을 중심으로 두고, 새 은하는 목적지 목록으로
추가할 수 있게 한다. 아직 없는 은하의 이름·잠금 조건·연구는 만들지 않는다.
안드로메다에서 돌아오면 은하 선택 화면으로 복귀한다. 기존 별자리 성도는
명시적인 보기 버튼으로 열고 다시 은하 선택으로 돌아올 수 있다.

5~10개 은하 전체와 새로운 최종 엔딩은 아직 설계하지 않는다. 아래의 107연구 /
국부은하군 29표식 / 기존 카탈로그 조건은 과거 구현·세이브 호환 데이터의 설명이며
현재 은하 선택 화면의 콘텐츠가 아니다. 이번 변경은 목적지 선택 화면과 진입 흐름에
한정한다. 과거 세이브 값의 삭제·재분배와 새 최종 엔딩은 별도로 결정한다.
