# 국부은하군 제거와 M31 보류 — 2026-09-10

사용자는 옛 은하계 29노드의 기능도 폐지하도록 요청했으며, 화면에서 숨기는 것만으로
끝내어 기능이 남아 있는 상태를 정리하도록 재지시했다. 천체는 등장 맥락과 역할을
다시 기획할 때까지 보류한다. 현재 문서의 호환·진단 경로 유지 설명을 재도입 근거로 쓰지 않는다.

이번 추가 결정: M31도 보류한다. 기존 은하 기준 좌표계 연구로 모듈을 열고,
M31 전용 record/revisit/reference_bus/shutter_weave 네 모듈은 뽑기·장착에서 제외한다.
기존 보유 수량은 보존한다. M31만 강화하는 세페우스자리 다섯 연구도 보류하며,
연구 소유 기록은 효과가 없는 별도 저장 필드로 옮긴다. 대체 천체·연구 효과는 만들지 않는다.

Git 조사에서 인공위성·변광성·혜성은 8월 24일, 쌍성·먼 은하는 8월 26일의
기존 별자리 확장에서 먼저 추가된 것으로 확인했다. 국부은하군 항성·행성 통과는
8월 28일, 초신성·블랙홀은 이후 개편에서 들어왔다. 9월 5일 지도 교체는 표시와
입력만 제거했고, 현재 M31 직접 관측은 9월 7일 별도 구현됐다.
이 작업은 국부은하군 잔재와 승인된 M31 연결 제거이며 기존 95개 연구는 유지한다.

국부은하군의 저장 ID가 재활성화를 일으키지 않도록 현행 연구 목록에서 삭제한다.
기존 데이터 잔액·관측 기록·나머지 연구·모듈 수량·표본은 유지한다.
기능 제거는 이전 구매 데이터의 환불이나 새 효과 지급을 뜻하지 않는다.

유성의 비행 거리가 배치 가능한 소멸 구역을 넘어가면 기존 횡단 경로로 화면 밖까지
진행한다. 속도·수명·감속 곡선은 유지하며, 공간 검사는 이 불가피한 이탈과
