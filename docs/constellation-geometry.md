# 별자리 좌표 기준

2026-09-11 사용자 승인으로 기존 12개와 확장 9개, 총 21개 도형 내부를 교정했다.
139개 표식 중 알페라츠는 안드로메다·페가수스가 공유하므로 실제 천체는 138개다.
M31 은하와 M45 성단도 표식 수에 포함된다. 연구 137개의 ID·효과·가격·선행 조건은 유지한다.

2026-09-13 게자리·궁수자리를 추가해 현재는 **23개 도형·158개 표식·150개 연구**다.
2026-09-14 방패자리 추가 후 현재는 **24개 도형·163개 표식·155개 연구**다.
방패자리 5별의 카탈로그·연결·실제 캡처 비교는 [항성과 초신성](stellar-supernova.md)에 기록한다.

게자리·궁수자리의 별 수 대조와 실제 성도 비교는 [후속 천체 연구](outer-celestial-research.md)에 기록한다.

## 앞으로 추가·변경할 때의 필수 절차

1. 구현 전에 실제 기준 성도와 천체 목록을 정한다. IAU / Sky & Telescope 성도와
   식별 가능한 실제 사진을 참고하고, 좌표는 출처가 명확한 천체 카탈로그에서 받는다.
   별자리 이름·IAU 코드·자료 URL·좌표 기준 시점과 각 별의 식별자를 기록한다.
2. **기준 도형의 별 수와 게임의 별 수를 일대일 대조한다.** 여기서 별 수는 별자리
   영역 안의 모든 희미한 천체가 아니라, 재현하기로 한 실제 도형을 구성하는 별 수다.
   연구 개수에 맞추려고 가상의 별을 추가하거나 실제 구성별을 임의로 생략하지 않는다.
   공유 별은 도형별 표식 수와 고유 천체 수를 구분하고, 은하·성단 표식은 별 수와
   별도로 적는다. 연구가 없는 장식별도 비교 목록에서 빠뜨리지 않는다.
3. 카탈로그와 생성기를 갱신해 실제 상대 위치·간격·비율·좌우 방향을 맞춘다.
   연결선은 채택한 성도의 동일한 별끼리 잇는지 확인한다. 연결 방식이 여러 개인
   도형은 어떤 자료를 따랐는지 적는다. 원본 좌표는 유지하며, 가까운 표식은 아래의
   2026-09-13 승인 범위에서 화면 표시만 보정할 수 있다.
4. 좌표·개수 검증과 관련 동작 검사를 실행한다. 새 도형을 추가하면 카탈로그,
   생성기·검사의 도형/표식 수 기대값과 캡처 대상도 함께 갱신한다.
   기존 수에 맞추기 위해 새 도형을 검사에서 제외하지 않는다.
5. **실제 게임을 실행해 영향을 받은 별자리마다 스크린샷을 찍고 기준 성도·사진과
   나란히 비교한다.** 회전과 균일한 축척 차이를 감안해 별 수·별의 대응·형태·연결을
   확인하고, 일반 보기와 확대 보기에서 잘림·겹침·연결선 누락·선택 불가도 확인한다.
   좌표 계산이나 자동 검사 통과만으로 화면 비교를 대신하지 않는다.
6. 완료 보고에는 출처, 기준/게임 별 수, 비교 이미지와 남은 차이를 남긴다.
   원본 게임 캡처도 보존하고 비교용 이름 덧표시·회전 등은 구분해 밝힌다.
   기준 도형을 간략화할 필요가 있으면 사용자와 결정하고 생략한 별과 이유를 기록한다.

이 절차는 기존 21개 도형을 완전한 성도로 소급 확장하라는 뜻은 아니다. 이번 교정은
기존 연구별의 간략형을 유지한 작업이며, 이후에는 새 도형의 구성별을 먼저 확정한다.
별자리 사이 전체 배치는 별도 결정이 없는 한 기존 연구 진행용 구성을 유지한다.

## 좌표와 도형

- [Yale Bright Star Catalogue V/50](https://cdsarc.cds.unistra.fr/viz-bin/cat/V/50)의
  J2000 적경·적위를 사용한다. M31·M45의 중심 좌표는 CDS Sesame/SIMBAD에서 받았다.
- 원본과 채택한 HR 식별자는 [research-stars.json](../tools/data/research-stars.json)에 있다.
  복수성 명칭은 기존 표식의 등급에 맞는 성분을 사용했다. 예: δ² Lyr, δ¹ Tau,
  θ² Tau, θ¹ Ori C. 쌍성계의 모든 구성원을 새 연구로 추가하지 않는다.
- 도형마다 별들의 평균 방향을 중심으로 입체 투영한다. 원본 좌표의 북쪽은 위,
  동쪽은 왼쪽이며 최장 별 간 거리를 로컬 2단위로 맞춘다. 별을 하나씩 이동하거나
  가로·세로를 따로 늘리지 않는다. 회전·동일 비율 축척 뒤의 화면 가독성 보정은 아래
  승인된 예외를 따르며 카탈로그 생성 결과에는 섞지 않는다.
- 페가수스는 알페라츠를 원점으로 삼아 **도형 전체**를 기존 안드로메다의 알페라츠에
  붙인다. 사각형 한 꼭짓점만 이동하지 않는다. 주변 도형과의 간격을 위해 도형 전체를
  회전하며 선택 이동은 실제 표식들의 중심을 사용한다.
- 전체 성도는 연구 진행용 배치다. 별자리 사이 실제 천구 위치, 관측 시각·위도,
  전체 천구의 단일 투영을 재현하는 변경은 아니다. 별 밝기의 UI 표현도 유지한다.

좌표를 갱신할 때:

```powershell
python tools/project_constellations.py
python tools/project_constellations.py --check
```

생성기는 표준 Python 라이브러리만 사용하고 두 GDScript의 `local_position`만 갱신한다.
별·연구 대응, 선행 조건, 연결선, 화면 앵커를 임의로 바꾸지 않는다.

## 연결선과 선택

페가수스 대사각형은 알페라츠 → 셰아트 → 마르카브 → 알게니브 → 알페라츠,
작은곰 국자 머리는 ζ → η → γ → β → ζ의 둘레로 교정했다.
돌고래의 꼬리는 β Del에서 ε Del로 잇는다.

IAU는 연결선 그림을 단일 공식 규격으로 정하지 않는다. 나머지는 현재 연구별을 잇는
간략형을 유지하며 IAU 성도의 모든 보조 별·선을 새로 추가하지 않는다.
작은곰의 기존 `deep_exposure → rapid_scan` 선행 조건은 보존하되 그 관계를 도형의
대각선으로 그리지 않는다. 필요한 선행 연구는 기존 정보창에서 확인한다.

가까운 별은 카탈로그 좌표를 보존하되 화면 표시에서는 최소 간격을 확보한다.
겹친 버튼은 표시된 중심에 가까운 별이 받고, 화면상 6px 이내의
분리하기 어려운 별 쌍은 연구 가능한 항목을 먼저 선택한다. 누르는 동안에는 대상이
바뀌지 않으며 길게 눌러 설치하는 기존 동작을 유지한다.

확장 도형은 캔버스의 음수 좌표에도 놓인다. 확대했을 때 Control의 기본 사각형이
화면 밖으로 나가더라도 연결선을 누락하지 않도록 그리기 범위를 성도 전체로 지정한다.
Control의 레이아웃 갱신 뒤에도 유지되도록 매번 다시 그릴 때 적용한다.

## 검증과 비교 자료

### 2026-09-13 밀집 노드 가독성 예외

사용자가 겹친 노드를 구별하기 위해 실제 별자리 위치에서 조금 벗어나는 것을 승인했다.
23개 도형의 원본 좌표·별 수·연결을 보존하고, 카메라 배율마다 표시 위치를 보정한다.
같은 도형의 가까운 표식 중심은 최소 18px, 본체 가장자리는 최소 6px 간격을 목표로
양쪽을 조금씩 벌린다. 확대하면 필요 없어진 보정은 줄어든다. 서로 다른 도형의 경계에서
겹치면 도형 전체를 평행 이동한다. 안드로메다·페가수스는 공유 알페라츠를 기준으로
함께 처리한다. 별자리의 회전이나 구매 상태가 바뀌어도 간격 계산은 다시 흔들리지 않는다.
원본 배치에서 다시 계산하므로 확대·축소를 반복해도 이동이 누적되지 않는다.

줄인다. 밀집 구간의 광원이 한 덩어리처럼 합쳐지는 것을 피하며 본체 크기는 유지한다.
