# 블랙홀

2026-09-13 사용자 요청: 일반 천체처럼 출현·이동하며 중력렌즈를 보이고,
관측 성공 시 일정 거리 안의 천체를 완료 위치로 당긴다.

후속 외형 수정: 사용자가 제시한 이미지처럼 검은 구체와 희미한 회보라색 가장자리,
주변 별빛이 둥글게 휘는 렌즈를 중심으로 표현한다. 첫 구현의 금색 기울어진 원반은
제거한다. 참조 이미지 자체를 게임 자산으로 쓰지 않고 기존 도형·셰이더로 구현한다.
검은 본체는 기존 관측 판정 반경 전체를 채우며, 판정·스폰·보상·당김은 유지한다.

## 첫 구현

- 기존 **행성 관측**(`galaxy_imaging`) 연구로 해금한다. 이번에는 새 별자리나
  별을 추가하지 않는다. 기존 저장의 연구 소유권으로도 해금된다.
- 고정 60틱에서 독립 추첨: 기본 틱당 **0.013333%** (`0.008 / 60`)에 기존
  출현 연구 배율을 적용한다. 일반 예보·진입·관측 파이프라인을 이용한다.
- 기본 이동 속도 28, 수명 32초, 관측 시간 4.8초, 기본 데이터 240.
  기존 수명·관측·보상 연구를 적용하며 몸체 반경은 38×0.84 월드 단위다.
- 블랙홀 전용 1자리에 잔상까지 포함한다. 기존 종류의 공간을 줄이지 않으며
  전체 비상 상한은 65(대기권 54, 후기 7, 표본 3, 거대 유성 1)다.
- 중력렌즈는 배경에만 적용한다. 이동 중 실제 천체 경로는 바꾸지 않는다.
  블랙홀이 없거나 화면 밖이거나 동작 강도 0%면 배경 복사를 끈다.
- 수동·자동 관측 완료 시 중심 반경 240px 이내의 살아 있는 일반 천체를 한 번
  모은다. 유성·파편·인공위성·소행성·혜성·행성·거대 유성이 해당한다.
  다른 블랙홀, 미출현 예보, 이미 끝난 천체, 별도 표본 천체는 대상이 아니다.
- 0.85초 동안 중심 주변으로 당긴다. 도착 거리는 25~49px + 각 본체 반경이며
  이미 가까운 천체를 밖으로 밀지 않는다. 당기는 동안 수명 진행을 멈추고,
  이후 1초간 이동·수명 진행 속도를 25%로 낮춘 뒤 원래 이동을 재개한다.
  수동·자동 관측은 계속 가능하고, 흡수·추가 보상·자동 완료는 발생하지 않는다.
- 완료한 블랙홀은 1.05초에 걸쳐 사라진다. 끌어당김은 완료 위치를 기억하므로
  블랙홀이 먼저 삭제돼도 이어진다. 재차 당겨지면 현재 위치에서 다시 시작한다.
- 동작 강도는 렌즈 강도와 완료 장식만 조절한다. 천체를 모으는 실제 기능은
  접근성 설정으로 없어지지 않는다. 섬광 끄기에서는 완료 밝기 강조를 끈다.
- 일반 진행 중 천체와 마찬가지로 이동 중 위치는 저장하지 않는다. 로드·회차
  정리 시 당김 상태도 천체와 함께 사라지며, 추가 보상이나 효과를 재생하지 않는다.
- `Ctrl+Shift+B`로 연구 없이도 블랙홀을 즉시 생성해 시험할 수 있다.

## 구현과 검증

`spawn_policy.gd`가 독립 출현을, `meteor.gd`가 관측 대상과 완료 연출을,
`gravity_capture.gd`가 당김·감속·경로 재설정을 담당한다. 당겨지는 천체만
메인 스레드 이동을 사용하고, 해제되면 기존 작업 스레드 경로에 다시 참여한다.
당김 중 별도 노드·타이머·전역 천체 간 쌍 비교를 만들지 않는다.

`scenes/black_hole_lens.tscn`은 배경 뒤버퍼와 로컬 렌즈를 소유한다. 배경 이후,
모든 관측 대상 이전에 렌더링한다. 화면 전체 복사는 활성 렌즈가 있을 때 한 번만
실행하며, 셰이더는 블랙홀 주변 사각 영역만 처리한다.
[Godot 화면 읽기 셰이더 문서](https://docs.godotengine.org/en/stable/tutorials/shaders/screen-reading_shaders.html)의
뒤버퍼 순서를 따른다. 배경이 희소하므로 별빛이 주변에 있을 때 왜곡이 가장 잘 보인다.

- `black_hole_test.gd`: 해금·예보·예약, 수동/자동 완료, 범위와 예외, 수명·보상,
  재당김·경로 복귀, 로드 정리, 132개 천체에서 직렬/병렬 이동 일치.
- `black_hole_review.gd`: 실제 완료 신호의 전/중/후 장면과 별빛 참조 격자의
  렌즈 꺼짐/켜짐 픽셀 비교. Vulkan·OpenGL에서 실행하며 왜곡 범위 밖은 같아야 한다.
- 변경 후 기본 검사·전체 경제 검사·렌더러 비교와 Windows 내보내기를 실행한다.

`build/black_hole_review/mobile/`, `build/black_hole_review/gl_compatibility/`에 있다.

실제 화면 캡처에서 원반 없는 검은 구체와 희미한 가장자리, 당김 중의 꼬리, 중심 주변으로 모인 본체와
렌즈 왜곡을 확인했다. 정지 장면 검토이며 실제 조작 감각과 후반 FPS는 추가 플레이로
판단한다. 한·영 연구 설명은 `build/solar_target_review/1789281839/`에서 확인했다.
