# 기능별 상세 기준

관련 기능을 수정할 때 필요한 현재 값과 동작이다. 전체 개발의 필독 목록이 아니다.
방향과 자율 조정 범위는 [현행 설계](design.md#개발할-때의-결정-범위)가 정한다.
여기 적힌 수치·배치는 현재 출발값이며, 조정한 항목은 결과 보고와 함께 갱신한다.
별도로 보류된 제안과 핵심 계약의 변경은 현행 설계의 결정 경계를 따른다.

2026-09-07 설계 원문에서 최종 유효한 결정을 모았다. 승인 사유·이전 값·사용자 답변은
[원문](history/design-through-2026-09-07.md)에 보존한다. 구현 소유권과 데이터 흐름은
[systems.md](systems.md), 검사와 시각·청취 검증은 [probes.md](probes.md)를 본다.

## M31과 모듈

### 진입과 구매

- 은하 기준 좌표계 이후 M31이 기존 하늘에 나타난다. 기존 커서로 누른 채 관측한다.
- 기본 분석 시간 10초, 보상 8,000 데이터, 완료 후 대기 7초다. 기존 은하 분석 속도와
  데이터 배율을 적용하고 기존 회차의 수입·성공 횟수에 합산한다.
- 첫 완료가 추가 비용 없이 모듈 연구와 편성을 연다. 모듈 없이도 첫 관측과 수입이 가능하다.
- 이후 특수 유성 1종, 바깥 별자리 10개·후속 연구별 47개, 총 모듈 14종으로 확장한다.
  추가 연구·표본 뽑기·사건·보상 조건은 [확장 설계](expansion-design.md)를 따른다.
- 구매는 기존 성도의 새 연구별을 길게 눌러 기존 데이터로 한다. 관측 연구는 영구 적용되며 모듈을 지급하거나 장착하지 않는다. 별도 사각 노드 트리를 사용하지 않는다.
- 편성은 연구탭의 팝업에서 무료로 한다. 관측 HUD에는 진입 버튼을 두지 않는다.
  별도 뽑기창에서 표본 잔액과 뽑기 비용·결과를 확인한다. 데이터 연구는 성도의 별에서 한다.
- 확장 성도의 왼쪽 목록에서는 완료한 기존 별자리를 숨기고 새 별자리의 진행을 보여 준다.
  모듈 편성·모듈 뽑기·바깥 별자리 메뉴는 그 아래에 세로로 배치한다.
  기존 별자리의 성도 좌표와 보유 연구는 유지한다.

### 장착 효과와 자리 연구

모듈 효과와 영구 연구 효과는 분리한다. 분열·광역·정밀·기록·재관측 모듈의
장착 효과는 [모듈 목록](expansion-design.md#모듈)을 따른다. 같은 ID를 가진 성도 연구는
[관측 성장 표](outer-constellations.md)에 있는 별도 영구 효과다.

| 자리 연구 | 선행 조건 | 비용 |
|---|---|---:|
| 세 번째 | 시작 프로토콜 | 240,000,000 |
| 네 번째 | 세 번째 자리 | 360,000,000 |
| 다섯 번째 | 네 번째 자리 | 480,000,000 |

최대 5자리, 처음 2자리가 열린다. 선행 연구와 데이터로 추가 자리를 연구한다.
효과는 장착 중인 같은 모듈의 증감분을 합산하고 다른 모듈끼리는 곱하며 기존 연구 효과와
다중 관측 능력을 유지한다. 분열+광역의 조합은 분열 확률 30%, 속도 ×0.75, 반경 ×1.65이며 기존
다중 관측을 유지한다. 기존 다중 분석 연구는 반경 안의 모든 유효 표적에 적용한다.
수동 속도 효과는 접시 자동화에 적용하지 않는다. 분열 관측은 수동·자동 성공 모두에 적용하며,
신규 접시 효과는 별도 조건을 따른다.
심층 기록·재관측은 M31 진행량에 비례해 수입·다음 대기 배율을 적분한다.
이미 진행 중인 대기는 장착 변경으로 소급 변경하지 않는다.
이 값들은 첫 구간 조정값이며 장기 경제와 완주 시간의 확정값은 아니다.

### 편성 동작과 표현

- 고리 맨 위부터 시계 방향으로 5자리를 둔다. 보관함 클릭은 첫 빈 열린 자리에
  장착하고, 고리의 장착 모듈 클릭은 해제한다. 장착한 모듈도 보관함에 어둡게 남긴다.
- 보관함은 획득한 모듈만 표시하며 전체·궤적·탐색·연계 분류와 3열 스크롤을 제공한다.
  상단에는 보유 종류 수를, 각 타일에는 보유·장착 수량을 표시한다. 미획득 모듈은
  모든 분류에서 숨긴다. 빈 보관함에는 뽑기창 안내를, 빈 분류에는 보유 없음 안내를 표시한다.
- 잠김·보유 수량 부족·가득 참은 상태를 바꾸지 않는다. 툴팁 마지막 줄에 사유와 가능한
  동작을 보여 주며, 잠긴 자리에는 필요한 페가수스 연구 이름을 표시한다.
- 드래그는 쓰지 않는다. 밑줄 닫기와 Esc로 닫고 연구창의 일시정지는 유지한다.
  연구창까지 닫으면 다른 일시정지 창이 없는 경우 관측을 재개한다.
- 기존 성도 툴팁 서식과 `ui_theme.gd` 색·서체를 사용한다. 편성의 모션은 기호 페이드와 테두리 밝기 0.28초다. 별도 뽑기창은
  판독 링·신호 정렬 1.8초와 결과 공개, 건너뛰기를 제공한다.
  기본 1152×648 뷰포트에서 설명·자리 이름은 최소 12px, 행동 안내·닫기는 14px로 표시한다.
  당시 좌표와 목업은 [완료된 편성 계획](history/module-loadout-plan.md)에 있다.

### 저장

모듈 보유, 길이 5의 `slots`, 열린 자리 수, M31 부분 진행·완료 기록·대기를 저장한다.
`deep_sky` v3는 소유 수량·표본·뽑기 결과·RNG·사건 티켓과 부분 기여도도 저장한다.
v2의 미선택 분석은 비용을 환불하며 구형 활성 표적의 진행률을 새 특수 유성으로 이전한다.
외부 슬롯 버전은 1을 유지하며 v1 모듈과 열린 자리를 보존한다. 확장 catalogue v3는
구형 모듈 구매에 대응하는 연구 ID를 한 번 복원하고 새 뽑기 소유권과 영구 연구를 분리한다.
옛 `equipped`/`secondary` 또는 두 칸 `slots`는 앞 두 자리에 복원하고 나머지는 잠긴 빈 칸으로 둔다.
별도 스테이지 저장의 구매·장착 모듈도 보존하되 옛 화면으로 다시 진입시키지 않는다.
보유 수량을 넘는 중복·미보유 항목 등 잘못된 데이터의 정리는 [저장 구현](systems.md#save-format)을 따른다.

## 관측과 자동화

- 커서로 조준하고 좌클릭을 유지한다. 중심에 가까울수록 속도·품질이 오른다.
  유성 수명은 동일한 연소 진행도의 감속·감광·꼬리 축소로 읽힌다.
- 하늘 훑기는 작은곰자리 연구로 열린다. 버튼을 유지한 채 표적 관측과 빈 하늘
  훑기가 자동 전환된다. 현재 표적과 추적 유예가 우선하며, 훑기로 부른 유성도
  버튼을 놓지 않고 관측한다. 관측 프레임의 이동을 훑기 충전에 중복 반영하지 않는다.
- 누른 채 모드를 바꾸면 부분 충전을 보존한다. 실제 버튼 놓기는 기본 충전을
  초기화하며 `sustained_sweep`만 회차 안에서 놓기 이후에도 보존한다.
  회차 종료·로드·리셋은 회차 충전을 초기화한다.
- 주변 150px에 살아 있는 유성이 없을 때 이동 거리를 충전해 커서 위치로 유성을 부른다.
  훑기 소환은 공명·폭풍을 연쇄 발동시키지 않으며 별도 상시 패널을 추가하지 않는다.
- 접시는 common·fast·fragment·fragment_piece를 처리한다. fireball·major는 수동 상품이다.
  이 경계는 속도가 아닌 타입으로 구분한다. 서보 460px/s와 고속 유성 436.8px/s의
  자동 완료 회귀를 유지한다. 예측 접시는 유휴 접시만 미리 배치하고 우클릭 수동 배치가 우선한다.
  별도 예약 입력·수동 분광 필터 버튼은 현재 조작에 포함하지 않는다.
- 예측 접시 제어 연구로 자동 배치가 활성화되면 접시의 범위 원·반투명 채움과
  이동 목적지의 범위 원을 숨긴다. 자동화 전에는 수동 배치를 위해 표시한다.
  자동화 이후에도 접시 위치 점과 이동·배정 연결선은 유지한다.
- 자동 성공은 관측 연속을 쌓거나 끊지 않는다. 소환의 출처 가드는 재귀 생성을 막는다.
  유성·예고·생성 큐는 회차 안에서 끝나지만, 사자 폭풍 충전과 후반 표적 기록·시계의
  지속 상태는 각 저장 계약을 따르며 일괄 초기화하지 않는다.

### 관측 연속과 하늘 활동

`observation_streak` 이후 커서의 남은 시간 호와 `연속 N회`(`Streak N`)는 실제 수동 연속 횟수다.
황소자리 연구는 제한 시간과 효과 적용 상한 4→5→7→10회를 바꾸지만 표시 횟수를
보상 배율이나 효과 상한으로 바꾸지 않는다.

`perseid_survey`의 활성 표적 3개 조건·보상은 유지한다. 커서의 적색광 표식 세 개로
현재 수와 임계 도달을 알리며, 표시·보상은 같은 추적 가능 대기권 표적 판정을 쓴다.
상시 패널이나 배율 숫자는 추가하지 않는 현재 표현을 기준으로 한다.

일반 유성 출현 간격과 동시 활성 상한은 독립된 런타임 값이다. 플레이어에게는
**Sky Activity / 하늘 활동**으로 묶되 각 연구가 바꾸는 값과 수치를 명시한다.
배경색·별 밝기를 바꾸는 `EventController.sky_activity_changed`와는 다른 설명이다.

## 연구 성도와 초반 구매

- 설치한 연구의 별이 밝아지고, 양 끝 연구를 설치해야 성도선이 완성된다.
  겉보기등급은 천체의 광도·크기를 뜻한다. 가격이나 티어와 섞지 않는다.
- 선행관계는 별자리 내부에 두고 뿌리는 처음부터 보인다. 성공 횟수 공개 게이트는 없다.
  용자리는 나머지 연구 86개의 실제 설치 뒤 열리는 최종 계열 예외다.
- 기존 12개 별자리에 후속 4개 별자리가 이어진다. 휠 회전·Ctrl+휠 확대축소·화면 맞춤·
  길게 눌러 설치를 제공하며 지평선 아래 별은 가리고 입력을 받지 않는다.
- 별자리 축척은 왼쪽 진행 목록과 오른쪽 고정 정보창을 쓴다. 중앙 하늘의 이름 나열과
  커서 추종 성도 툴팁은 현재 구성에 포함하지 않는다. 은하 축척의 정보도 고정 영역에 두며
  실제 은하 코드 라벨을 유지한다. 모듈 편성 팝업의 호버 툴팁은 별개다.
- 기준 좌표계의 3.6초 물러남은 기존 별과 선을 유지하면서 바깥 별자리를 드러낸다.
  엔딩이 아니며 살아 있는 회차를 끝내지 않는다. 같은 좌표계와 회전·확대를 유지하고
  한 번 재생한 상태를 저장한다. 왼쪽 별자리 이름을 누르면 해당 별자리를 바라본다.
- 새 연구별은 식별용 베이어 명칭과 연구 효과를 고정 정보창에 표시한다. 새 별자리
  이름 4개는 성도에서 위치를 알려 준다. 선행 조건과 별자리 형상의 연결선은 구별한다.

| 초반 연구 | 현재 가격 |
|---|---:|
| 개량 렌즈 | 10 |
| 장노출 | 50 |
| 경계 탐지 | 50 |
| 관측망 설계 | 110 |
| 하늘 훑기 | 120 |

현재 초반 예산 기준은 50~100 데이터에서 선택이 한꺼번에 몰리지 않도록 한다.
시작 시 구매 가능 연구는 렌즈·경계 탐지, 튜토리얼 렌즈 구매 뒤에는 장노출·경계 탐지다.
추가 수입 없는 정산에서 50 데이터는 최대 1개, 100 데이터는 최대 2개를 살 수 있다.
공개·선행 조건·효과는 이 가격 조정에서 바꾸지 않았다. 전체 가격 곡선의 확정값은 아니다.

## 공간과 표적 예산

공유 관측 코드의 기본 뷰포트와 세로 안전 영역은 1152×648이다. 유성 활동 영역의
좌우는 보이는 월드에 맞추되 세로 안전 범위를 유지한다. 입력 반경은 화면상 크기를
유지하고 유성 그림은 관측 폭의 제곱근만큼 물러난다. 배경·지평선은 보이는 영역을
채워 고정 영역의 테두리가 드러나지 않게 한다.

일반 활성 유성의 최종 상한은 18, 모든 유성 출처가 공유하는 전역 상한은 32다.
예고와 장기 관측 대상은 일반 활성 유성 예산을 소모하지 않는다.
이전 국부은하군의 관측 폭 확장 단계는 [호환 계약](legacy-contracts.md#공간과-예산)에 있다.

## 표현과 설명

### 관측 화면과 성도

- 낮은 대비의 하늘, 희소한 별, 얇은 꼬리와 작은 비대칭 핵을 기준으로 한다.
  둥근 테두리 패널·장식 좌표 그리드·가공 코드명/수치, 천체 사진·성운 구름·
  필름 그레인·센서 노이즈를 배경 장식으로 추가하지 않는 기존 방향을 유지한다.
- 데이터 계기는 하단, 작은 회차 시계는 왼쪽 상단에 모아 중앙 관측 공간을 확보한다.
  관측 범위·진행은 채움 없는 얇은 백색 링으로, 대상 이름과 진행률·현재 조준 상태는 두 줄로 표시한다.
  조준은 중심·안쪽·가장자리·이탈을 구분하며 완료율을 등급으로 해석하지 않는다.
  최종 등급은 수동 관측 완료 시 실제 누적 품질 판정으로 보상 표시에 함께 붙인다.
  화면 가장자리에서 잘리지 않게 하고 글자 크기의 극단적 격차를 피한다.
- 유성 꼬리의 빛 중심선은 실제 궤적을 따른다. 낮은 지형의 겹침과 관측소 돔·접시
  실루엣으로 장소감을 표현한다. 표현 수정만으로 수명·입력 판정·경제·저장을 바꾸지 않는다.
- 연구 계열색은 적색광 상태 잉크에 제한적으로 섞는다. 계열은 미세한 색차로,
  상태는 명도·채움·고리·미광으로 구분한다. 별·성단·은하에 적용하며 잠김·예고·숨김에는
  섞지 않는다. 원색 13개로 채우거나 더 강한 계열색으로 바꾸는 제안은 별도 보류 상태다.

### 소리와 사건 강조

연구는 두 음, 슬롯은 조용한 비음정 클릭, 희귀 출현은 빠른 두 음, 환경 변화는
완만한 긴 음으로 구분한다. 자동 성공은 160ms 동안 집계해 70ms 펄스 하나로 내고
음량만 제한적으로 가중한다. 수동 성공의 음계와 즉시성은 유지한다.
미재생 자동 집계는 일시정지·회차 경계·로드에서 비우며 연구·슬롯 UI 소리는 일시정지 중에도 난다.

일상 관측은 방향성 입자와 데이터 packet을 기본으로 한다. 긴 콤보·경제 배율·
유성우/메아리 출처만으로 강조하지 않는다. fireball/major, 높은 수동 등급, 통과 수확과
현상 완료만 강조 자격을 얻고, 실제 링·섬광·킥·shake·hitstop은 각 임계값과
은하 단계 섬광 억제를 따른다. 현상 완료 자체의 무섬광 계약도 유지한다.
구현별 임계값은 [관측 흐름](systems.md#observation-flow)에 있다.

연구 설치는 실제 보이는 정보창의 기존 1px 선을 0.28초 동안 20%에서 전체 길이로 켠다.
닫힌 성도에서는 HUD 배너 선을 쓰고 하늘 섬광·흔들림을 추가하지 않는다.
선택·공지·축척·화면이 바뀌면 취소하며 기준 좌표계는 물러남만 유지한다.

### 용어와 효과 설명

- **Observation Streak / 관측 연속**은 수동 성공의 연속 횟수다.
  관측 속도·회차·진입 예고·예상 위치 오차·종류 미확인·하늘 훑기·장기 관측 대상·먼 은하·
  은하 지도를 구분한다. 용어 수정만으로 내부 ID를 바꾸지 않는다.
- 효과 본문은 증가율 또는 전후 값을 먼저 보여 준다. 단순 강화는 한 문장,
  복합 효과·필수 조건은 짧게 덧붙인다. 장점·사용 상황의 장황한 설명과 가공 수치는 피한다.
- 공명은 추가 유성 출현으로 설명한다. 분광 대역은 화면색과 같다고 가정하지 않고
  적용 천체를 열거한다. 함께 필요한 연구와 다음 회차 적용 조건을 명시한다.
- 거리·반경 설명은 픽셀 대신 변화율 또는 화면 너비 비율을 쓴다. 고정 거리 가산은
  초기 반경 기준임을 밝히며 반올림에는 `약`을 붙인다. 누적 배율 대신 해당 연구의 효과와 대상을 쓴다.
- 연구 효과 본문은 1080p 출력 기준 약 15px 보통 굵기와 정보창의 전체 본문 폭을 쓴다.
  한국어·영어가 같은 동작을 설명하고 튜토리얼의 연구 계열과 수동 저장 슬롯 3개를 구별한다.
- 설정·조작·접근성 세부사항은 [설정 참조](settings.md)를 본다.

## 저장과 검증의 공통 경계

기존 별자리 연구 95개의 ID와 저장 호환성을 유지한다. 표현 상태와 진행 상태를 구분한다.
옛 국부은하군 ID 처리와 이전 엔딩 저장은 [호환 계약](legacy-contracts.md)에 있다.
현재 저장 형식과 일시정지 소유권은 [시스템 참조](systems.md)를 따른다.

기계적 게이트는 동작·수치·경계를 검증한다. 정지 캡처는 화면 배치의 근거다.
실시간 밀도·조작감·피로·재미는 실제 빌드의 플레이로 판단한다. 결과에는 환경·시드·소스를
기록하고 역사값을 현행 합격선으로 재사용하지 않는다. 검증 범위는 [probes.md](probes.md)를 따른다.
