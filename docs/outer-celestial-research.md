# 확장 이후 천체 연구

2026-09-13 사용자 승인에 따라 소행성·얼음 소행성을 확장 이후로 옮기고,
행성과 블랙홀에 각각 게자리·궁수자리를 배정했다.

항성 추가 후 현재 수치·판정·방패자리 기준은 [항성과 초신성](stellar-supernova.md)을 따른다.
방패자리는 은하 기준 좌표계에서 바로 갈라지는 초반 가지다. 아래 화살자리에서
블랙홀로 이어지는 경로는 유지한다. 화이트홀은 궁수자리 이후 봉황자리로 이어진다. 현재 후속 연구는 13별자리·66개다.
[화이트홀과 봉황자리](white-hole-preview.md)에 추가 경로와 실제 성도 대조를 기록한다.

## 진행과 효과

은하 기준 좌표계 → 화살자리 소행성 관측 → 소행성 탐색 → 얼음 소행성 관측
→ 게자리 행성 관측 → 행성 추적 → 궁수자리 블랙홀 관측으로 이어진다.
이전 별자리 전체 완성이나 모듈 수집은 요구하지 않는다.

- 화살자리 5개: 소행성·얼음 소행성 해금, 두 종류의 출현 확률 ×1.35,
  수동·자동 관측 속도 ×1.3, 데이터 ×1.5.
- 게자리 5개: 행성 해금, 출현 확률 ×1.755, 수동·자동 관측 속도 ×1.3,
  데이터 ×1.95. 각 강화는 해당 천체에만 적용한다.
- 궁수자리 8개: 블랙홀 해금, 출현 확률 ×1.35, 수동·자동 관측 속도 ×1.3,
  데이터 ×1.5. 당기는 반경은 240 → 300 → 360px,
  당긴 뒤 감속 시간은 1 → 2 → 3초다. 당기는 시간 0.85초와 감속 배율 25%는 유지한다.

확률 배율은 기존 고정 60틱의 종류별 독립 추첨에 곱한다. 추첨 순서와 난수 스트림,
진입·예보·관측 방식, 외형과 다른 종류의 기본 출현 확률은 그대로다.
화살자리의 과거 일반 출현·예보·수명 강화는 위의 소행성 전용 효과로 대체했다.
각 연구 가격·선행·짧은 설명은 [바깥 별자리 표](outer-constellations.md)에 있다.
새 연구 13개의 비용은 1.015B, 후속 연구 전체 55개의 비용은 2.66B 데이터다.
초기 조정값이며 사람 플레이의 완주 시간을 확정한 가격은 아니다.

## 기존 연구와 저장

기존 95개 연구별의 좌표·ID·선행은 유지한다. 가격·데이터 배율은 2026-09-14 구매 빈도 조정을 적용한다.

| 기존 ID | 현재 이름 | 기능 |
|---|---|---|
| `variable_watchlist` | 장기 표적 추적 | 인공위성·혜성 수동 관측 속도 +30% |
| `double_star_resolution` | 정밀 분석 | 모든 관측 데이터 1.5배, 정확한 얼음 소행성 예보 |
| `galaxy_imaging` | 심우주 분석 | 모든 관측 데이터 1.5배 |

정밀 분석과 심우주 분석의 기존 전체 데이터 배율은 자동 관측에도 유지한다.
별자리의 M31 표식은 실제 은하의 연구 표식으로 남으며 행성이나 블랙홀 해금을 맡지 않는다.
M31 전용 관측 콘텐츠나 폐지한 국부은하군 연구를 복구하지 않는다.

저장 카탈로그는 버전 5다. 기존 연구 소유권·모듈·표본을 지우거나 환불하지 않는다.
이미 구매한 화살자리 ID는 대응하는 새 효과로 적용하며 새 게자리·궁수자리는 직접 연구한다.
기존 기본 연구만 보유한 저장에서는 큰 천체가 더 이상 자연 출현하지 않고 새 해금을 따른다.
새 저장은 기본·후속 연구 ID를 모두 유지한다.
추가 검사에서 JSON의 `4.0`을 정수 목록 `[1, 2, 3, 4]`와 비교해 정상 저장을 거부하는
기존 버전 검사 오류를 발견했다. 유한한 정수값 1~4인지 확인하도록 고쳐 JSON 저장을
실제로 복원하며, 소수·불리언·문자열·미래 버전은 계속 거부한다. 진행 중 하늘과 당김은 기존 로드 규칙대로 비운다.
인공위성 예보를 숨기는 진행 단계도 새 소행성 관측 해금으로 옮겼다.

## 실제 별자리 자료와 수 대조

- 기준 그림: IAU / Sky & Telescope의
  [게자리 CNC](https://iauarchive.eso.org/static/public/constellations/pdf/CNC.pdf),
  [궁수자리 SGR](https://iauarchive.eso.org/static/public/constellations/pdf/SGR.pdf).
- 좌표: [Yale Bright Star Catalogue V/50](https://cdsarc.cds.unistra.fr/viz-bin/cat/V/50)의
  J2000 적경·적위. 채택한 HR과 좌표는 `tools/data/research-stars.json`에 보존한다.
- 게자리: ι(HR3475), γ(3449), δ(3461), α(3572), β(3249), **기준 5별 = 게임 5별**.
  ι는 밝은 성분 HR3475를 채택하고 희미한 동반성 HR3474를 별도 도형별로 추가하지 않았다.
  ι–γ–δ, δ–α, δ–β 연결을 재현한다. M44·M67은 선택한 연결 도형의 별이 아니다.
- 궁수자리: γ²(HR6746), δ(6859), ε(6879), ζ(7194), τ(7234), σ(7121),
  φ(7039), λ(6913), μ(6812), η(6832), ρ¹(7340), π(7264), ο(7217), ξ²(7150).
  **기준 14별 = 게임 14별**. 주전자 8별을 연구로 쓰고 μ·η와 ρ¹–π–ο–ξ²는
  연결된 보조 별로 유지한다. 별도로 떨어진 네 별을 주전자에 임의 연결하지 않았다.
- 기존 화살자리는 5별·5연구와 원래 좌표·연결을 유지하고 연구 효과만 바꿨다.
- 전체는 기존 12개 + 확장 11개 = 23개 도형, 150개 연구와 158개 표식이다.
  공유 알페라츠를 한 번 세면 고유 천체 157개다. M31 은하와 M45 성단도 표식 수에 포함한다.

도형별 입체 투영, 북쪽 위·동쪽 왼쪽, 균일 축척과 카메라 회전을 적용한다.
새 천체 연구를 더 바깥에 구분해 두기 위해 게자리 앵커는 반경 1240·각도 −0.42,
궁수자리는 반경 1280·각도 −1.1로 놓았다. 이는 연구 성도의 배치이며 실제 천구에서의
별자리 사이 위치를 재현하지 않는다. 개별 별을 늘리거나 옮기고 반전하지 않았다.

## 검증 기록

최종 `build/validation/20260913T115805990Z_3943cb8d/summary.json`: 기본 26개,
전체 경제 검사와 Windows 내보내기까지 **28개 통과**. 경제 검사는 3개 시드 모두
기존 95개 연구를 완성하고 수입·지출이 일치했다. 실행 파일은
`build/windows/NightwatchArray.exe`로 갱신했다.

- `project_constellations.py --check`: 23개 도형·158표식 재생성 일치.
- `constellation_geometry_test.gd`: 실제 실행 위치와 카탈로그 각거리·좌우 방향 대조.
- `constellation_extension_test.gd`: 전체 11개 확장 목록 이동, 게자리·궁수자리의
  모든 연구별 선택, 목록과 하단 버튼의 겹침, 기존 연구 구매·저장 검사.
- `black_hole_test.gd`: 기존 기본 연구에서 출현하지 않음, 별자리 전체 완성 없이
  다음 해금 도달, 종류별 확률·보상과 실제 자동 관측 진도, 완료 시 360px 안팎 판정,
  3초 감속·해제, 기본/후속 연구 저장 왕복과 v4 화살자리 구매 이관 검사.
- 실제 Vulkan 게임 캡처 31장: `build/constellation_geometry_review/1789300115/`.
  23개 도형별 확대와 두 전체 보기, 새 천체 별자리 3개의 한국어·영어 일반 선택 보기다.
  새 별자리의 잘림·연결선 누락이 없고, 마지막 목록 줄도 모듈 버튼 위에 표시됨을 확인했다.
- 성도와 나란히 비교: `build/outer_celestial/constellation-comparison.png`.
  게임 원본의 별 이름은 비교용으로만 덧표시했다. 회전·평면 투영 차이가 있으며,
  실제 밝기와 UI 연구 완료의 밝기 표현은 다르다. 새 도형에 추가 생략이나 왜곡은 없다.

전체 경제 검사는 기존 95개 연구의 자동 전략 회귀 검사다. 새 연구의 도달성은 검사하지만
후속 연구 55개 전체의 사람 플레이 속도·재미까지 검증한 것은 아니다.
