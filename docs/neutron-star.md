# 중성자별과 초신성 잔해

2026-09-15 사용자 승인에 따라 중성자별을 펄서로 구현하고 초신성 외형을 조금 더
자연스럽게 바꿨다. 이번에는 새 별자리를 만들지 않고 기존 방패자리의 마지막
광역 초신성 연구에 연결한다. 기존 162개 연구·가격·기본 초신성 보상은 유지한다.

## 실제 천체와 표현상의 타협

[NASA 중성자별 설명](https://imagine.gsfc.nasa.gov/science/objects/neutron_stars1.html)의
초신성 잔해·고밀도 소형 본체·회전하는 자기축과 등대형 방출을 출발점으로 삼았다.
중성자별의 물리적 크기는 도시 정도지만 게임에서는 선택할 수 있도록 지름 약 19px의
본체와 넓은 관측 범위를 사용한다. 자기축을 자전축에 기울여 투영하며 작은 밝은 영역과
선명한 양극 방출을 표현한다. 보이는 빔은 전파·고에너지 방출의 시각화이고 실제 가시광
레이저를 재현하는 것은 아니다. 회전 시간 1.6초는 읽기 쉬운 게임 시간 축척이다.

일반 중성자별·강착계·마그네타의 특징을 혼합하지 않는다. 강착 원반과 주기적인
전방위 폭발은 추가하지 않는다. 관측 완료 자체가 별을 파괴하지 않으며 완료 후에도
잠시 회전·이동하다 시야에서 흐려진다.

## 발생과 관측

- 광역 초신성 연구 후 정상적으로 관측을 완료한 항성에서 35% 확률로 생성한다.
  초신성의 2초 연출을 끝낸 위치에, 원래 진행 방향으로 속도 24px/s로 나타난다.
  미관측 만료·회차 정리로는 생성하지 않는다. 새로운 자연 출현 추첨은 없다.
- 출현 판단은 저장된 항성 난수 상태와 해당 항성의 출생 시드를 조합한 지역 추첨이다.
  기존 자연·예보·파편 난수 스트림은 소비하지 않는다. 방패자리 해금 전에는 실행하지 않는다.
- 항성과 중성자별은 완료 후 잔상까지 합쳐 3자리를 공유한다. 부모를 제거 예약한 뒤
  자식을 생성하므로 상한에 도달해도 정상적으로 교체한다. 전체 안전 상한 70은 유지한다.
- 회차에 수축·폭발 2초와 중성자별 관측 여유 6초가 남아 있을 때만 예약한다.
  생성 시에도 남은 시간을 재확인하고, 일시정지는 생성 일정·회전을 함께 멈춘다.
- 기본 수명 18초, 관측 시간 계수 3.2초, 데이터 600, 판정 반경 12이다.
  기존 일반 연구와 관측 보상 경로를 사용한다. 빔이 시선 쪽을 지날 때 신호가 강해진다.
  관측 속도는 회전 위상에 따라 0.35~2배이며 수동·접시·자동 보조에 동일하게 적용한다.
- 진행도는 추적 중단·약한 신호에서도 감소하지 않는다. 클릭 타이밍 입력을 요구하지 않고
  계속 추적해 여러 번의 신호를 누적한다. 다른 초신성으로 즉시 관측할 수 없다.
- 완료 시 한 번만 데이터를 받고 추적 대상에서 빠진다. 3초간 원래 방향으로 이동하면서
  회전하는 양극 빔으로 유성·소행성·얼음 소행성·행성의 관측을 돕고 마지막 0.8초에 흐려진다.
  항성·블랙홀·화이트홀·다른 중성자별과 모듈용 특수 표본은 대상에서 제외한다.
- 빔의 한쪽 최대 길이는 평상시 150px에서 완료 후 190px로 늘어나며, 자기축의 투영에 따라
  화면상 길이가 달라진다. 그려진 빔과 판정은 같은 자기축·길이를 사용한다. 천체의 본체 반경도
  접촉 판정에 포함하며 빔 가장자리·끝으로 갈수록 관측량이 줄어든다. 카메라가 멀어질 때도
  빔 판정은 천체 표면의 표시 축척을 따르므로 보이는 끝보다 바깥까지 관측하지 않는다.
  중심 최대 속도는 초당 진행도 4.0이고, 여러 중성자별의 빔은 자동 관측 속도로 합산한다.
  빔을 반복해서 맞아 진행도가 가득 차면 기존 완료·보상 경로를 한 번만 실행한다.
  이 관측 지원은 실제 천체 관측을 그대로 재현한 물리가 아니라 게임 효과다.
- 매 틱 현재 하늘의 빔 접촉을 다시 계산한다. 빔이 돌아가거나 출처가 사라지면 지원이 끊기고,
  화면 밖 천체·출현 예고·같은 틱에 생긴 자식 천체에는 작업을 넣지 않는다.
- 동작 줄이기·섬광 끄기는 빔·본체 애니메이션에만 적용하며 실제 신호·관측 규칙은 유지한다.
  저장은 기존 연구 소유권을 보존한다. 비행 중 천체와 대기 중인 잔해는 다른 천체처럼
  저장하지 않으며 불러오기·회차 종료·리셋에서 정리한다. 경제 시뮬레이터에 잔해를 포함한다.

2026-09-15 존재감 보강: 사용자가 외형과 게임 효과를 모두 강화하도록 선택했다.
기본 데이터를 240 → 600으로 올리고 위의 관측 지원을 추가했다. 작은 고밀도 본체를 유지하며
양극 빔의 밝은 중심선·넓은 외피·내부 흐름을 보강하고, 신호가 시선을 향할 때 중심부의
빛 번짐을 강화했다. 등장 발광은 0.75초 동안 가라앉고 완료 후에는 빔이 더 길고 밝아진다.
동심원 충격파나 강착 원반을 더하지 않았다. 섬광 끄기에서는 맥동·등장 발광을 줄이고,
동작 강도 0에서는 회전·빔을 숨긴다. 자동 관측 판정은 접근성 설정으로 바뀌지 않는다.
0보다 큰 동작 강도에서는 빔 밝기를 낮추되 회전 위상은 실제 관측 판정과 맞춘다.

## 초신성 외형

기존의 날카로운 동심원 2개·규칙적인 방사형 선 18개를 없앴다. 장면 리소스와 지역
셰이더가 불규칙한 밀도·두께의 가스층, 팽창하며 옅어지는 주황빛 잔해와 부드러운
중심부를 그린다. 중심의 밝기는 초반에만 집중하고 주변 화면을 흰색으로 덮지 않는다.
동작 강도 0에서는 가스 팽창을 숨기고 차분한 중심부의 소멸만 남긴다.
충격파 반경·즉시 관측 시점·보상은 그대로다. 2026-09-16 후속 연출 요청에 따라
항성의 수축·폭발 완료 시간은 2초이며, 잔해는 이 연출이 끝난 뒤 나타난다.
실제 초신성과 잔해 진화의 긴 시간과 복잡한 물리는 압축한 표현이다.

## 구현과 검증

- `stellar_meteor.gd`: 폭발 후 잔해 예약·해제. `meteor_spawner.gd`: 해금·추첨·생성·상한.
- `neutron_star_meteor.gd`: 회전 신호와 관측 누적, 완료 후 빔 접촉·이동.
- `game.gd`: 현재 틱의 빔 지원 초기화·합산. `meteor.gd`: 기존 자동 관측 속도에 빔 지원 합산.
- `neutron_star_surface.tscn`, `supernova.tscn`: 인스턴스별 셰이더와 안정된 시각 구조.
- `neutron_star_test.gd`: 해금 전후, 난수 격리·복원, 지연 생성, 공유 상한, 신호별 실제
  관측량, 중단 시 진행도 보존, 다른 초신성 제외, 일시정지·퇴장·불러오기·회차 정리.
  양극 접촉·거리·회전·제외 대상·자동 완료·중복 보상 방지·출처 소멸과 직렬/작업자 일치를 검사한다.
- `neutron_star_review.gd`: 실제 입력 버퍼로 항성·중성자별을 수동 관측한 16초·30fps
  PNG 시퀀스, 주변 천체 관측 완료, 퇴장 픽셀 밝기 감소와 접근성·한영 연구 설명. 양 렌더러의
  `build/neutron_star/<renderer>/manifest.json`에 결과를 남긴다.
- 기존 항성·렌더링 검사 및 `tools/validate.ps1 -FullEconomy -Build`를 함께 실행한다.

사용자의 실제 저장을 바꾸지 않는다. 사람의 플레이 경험이나 최종 경제 검증을 대신하지 않는다.
