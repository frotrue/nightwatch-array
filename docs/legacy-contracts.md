# 폐지 콘텐츠의 저장 처리

2026-09-10 사용자 정정에 따라 국부은하군과 카탈로그 엔딩은 실행 코드에서 제거했다.
과거 기능을 유지해야 한다는 계약은 더 이상 유효하지 않다.
[결정과 범위](history/content-retirement-2026-09-10.md)를 따른다.

- 기존 별자리 95개 연구만 활성 정의로 로드한다. 삭제된 국부은하군 연구 ID는 무시한다.
- 항성·행성 통과·초신성·블랙홀·렌즈 유성·옛 엔딩 상태는 복원하거나 다시 저장하지 않는다.
- 데이터 잔액·관측 기록·유효 연구·모듈 수량·표본은 유지한다. 새 효과나 환불을 자동 지급하지 않는다.
- M31 진행은 `deep_sky.retired_m31`에 실행되지 않는 기록으로만 보존한다.
- record/revisit/reference_bus/shutter_weave 소유 수량은 보존하고 장착은 해제한다.
  활성 모듈 정의와 뽑기 풀에는 이 ID들이 없다.
- M31 전용 다섯 연구는 `extension.retired_research_ids`에 보존한다.
  가격·효과·선행 조건을 가진 활성 정의는 제거했다.
- 새 저장은 deep_sky version 4 / catalogue version 4다. 1~3 버전을 읽되 미래 버전은 거절한다.
- 재기획 전까지 호환 데이터를 천체·연구·보상으로 다시 연결하지 않는다.

과거의 107연구·12+17표식·5개 현상·관측 폭 확장 수치는 역사 자료이며 현행 검증 기준이 아니다.
`content_retirement_test.gd`가 디버그·이전 저장·재저장을 통한 재활성화 방지를 확인한다.
