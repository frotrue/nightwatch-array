# 바깥 별자리의 관측 성장

2026-09-08 사용자 승인: 확장 영역에 별자리 약 10개를 만들고, 모듈 계열은
1~2개로 제한한다. 나머지는 기존처럼 관측을 성장시킨다. 이에 따라 **10개 별자리,
47개 연구별**로 구성한다. 기존 연구 ID 18개는 유지하며 새 연구별 29개를 추가한다.
기존 하늘의 연구별 95개와 합쳐 진행 계기는 142개다.

모듈 지원은 페가수스·도마뱀자리의 10개 연구다. 나머지 8개 별자리의 37개 연구는
장착 없이 영구 적용된다. 기존 제어 방식·표적 종류·회차 길이·표적 총량 제한은 유지한다.
이 영역의 연구는 첫 M31 관측 이후 선행 연구와 데이터로 구매한다. 모듈 보유나 뽑기 결과를
선행 조건으로 삼지 않는다. 총 연구 비용은 9.06B 데이터이며 기존 확장 가격대에서 배치했다.
이는 전체 게임의 목표 완주 시간을 확정한 값이 아니다.

## 연구 상세

같은 효과를 강화하는 서로 다른 연구의 배율은 곱하고, 시간·횟수·확률 증가량은 더한다.
모듈의 같은 종류 중복 장착 규칙과는 별개의 영구 연구다. 가격 단위 M은 백만 데이터다.
이미 완료한 연구는 선행 조건을 다시 확인해서 취소하지 않는다.

## 적용과 보존

- 연구 상태는 `deep_sky.extension.research_ids` 한 곳에서 저장한다. ProgressionController는
  이 상태의 파생 효과를 읽고 기존 관측 공식 뒤에 적용한다. 모듈 교체로 영구 효과가 사라지지 않는다.
- 연구 구매 후 기존 유성의 분석 설정과 실제 접시 수를 갱신한다. 유성의 수명·생성 간격·예고는
  다음 생성/예고부터 적용하고, 현재 진행 중인 사건을 다시 생성하거나 보상을 소급 지급하지 않는다.
- M31 보상·다음 대기 배율은 영구 연구와 장착 모듈을 합친 상태를 실제 관측 진행량으로 적분한다.
  이미 시작된 대기는 바뀌지 않는다. 구형 저장의 기존 부분 진행량과 적분값은 보존한다.
- catalogue version 3 이전 저장은 확정 구매 5종에 대응하는 연구 ID를 한 번 복원하고,
  구형 연구 보상 3종도 보존한다. 현재 버전에서 모듈을 얻는 행위는 연구 완료로 해석하지 않는다.
- 원래 95개 별의 좌표와 페가수스의 공유 알페라츠는 유지한다. 10개 별자리는 같은 회전·확대
  성도에 연결하고 왼쪽 목록을 누르면 해당 별자리를 지평선 위로 가져온다.
