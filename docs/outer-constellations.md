# 바깥 별자리의 관측 성장

2026-09-13 천체 연구 이동을 반영한 현재 구성은 **11개 별자리·55개 연구별**이다.
기존 95개 연구와 합쳐 성도 진행 계기는 150개다. 모듈 지원은 페가수스·도마뱀자리의
10개 연구이며 나머지 9개 별자리·45개 연구는 장착 없이 관측 능력을 키운다.
은하 기준 좌표계 연구 이후 선행 연구와 데이터로 구매하며 모듈 보유나 뽑기 결과를 요구하지 않는다.
M31 전용 세페우스자리 5개 연구는 삭제하고 과거 소유 기록만 따로 보존한다.
총 활성 후속 연구 비용은 14.10B 데이터다. 전체 목표 완주 시간을 확정한 값은 아니다.

## 별자리 역할

성도 위에는 별자리 이름을 상시 표시하지 않는다. 기존 별자리와 같은 방식으로 별과
연결선만 두고, 이름은 왼쪽 별자리 목록과 선택 정보창에서 확인한다.

| 도마뱀자리 | 5 | 특수 유성 표본 |

## 연구 상세

같은 효과를 강화하는 서로 다른 연구의 배율은 곱하고, 시간·횟수·확률 증가량은 더한다.
모듈의 같은 종류 중복 장착 규칙과는 별개의 영구 연구다. 가격 단위 M은 백만 데이터다.
이미 완료한 연구는 선행 조건을 다시 확인해서 취소하지 않는다.

## 적용과 보존

- 연구 상태는 `deep_sky.extension.research_ids` 한 곳에서 저장한다. ProgressionController는
  이 상태의 파생 효과를 읽고 기존 관측 공식 뒤에 적용한다. 모듈 교체로 영구 효과가 사라지지 않는다.
- 연구 구매 후 기존 유성의 분석 설정과 실제 접시 수를 갱신한다. 유성의 수명·생성 간격·예고는
  다음 생성/예고부터 적용하고, 현재 진행 중인 사건을 다시 생성하거나 보상을 소급 지급하지 않는다.
- M31의 구형 부분 진행량·적분값은 실행되지 않는 저장 기록으로 보존한다.
- catalogue version 3 이전 저장은 확정 구매 5종에 대응하는 연구 ID를 한 번 복원하고,
  구형 연구 보상 3종도 보존한다. 현재 버전에서 모듈을 얻는 행위는 연구 완료로 해석하지 않는다.
- 원래 95개 별의 좌표와 페가수스의 공유 알페라츠는 유지한다. 11개 별자리는 같은 회전·확대
  성도에 연결하고 왼쪽 목록을 누르면 해당 별자리를 지평선 위로 가져온다.

새 해금 경로·기존 저장의 적용 방식·실제 성도 비교는 [천체 연구 이동](outer-celestial-research.md)을 따른다.
