# 현행 설계

Nightwatch Array의 방향과 개발 판단 기준이다. 작업을 시작할 때 이 문서를 읽고,
수치·상태·화면 세부사항은 해당 기능의 [상세 기준](design-details.md)만 찾아본다.
구현 책임은 [systems.md](systems.md), 검증 방법은 [probes.md](probes.md)에 있다.

2026-09-07 정리: 기존 콘텐츠 결정을 유지하고, 같은 날 사용자가 승인한
**소규모 UI·연출·밸런스 조정의 자율 진행과 결과 보고**를 개발 기준에 반영했다.
이전 결정과 대체 이유는 [정리 전 원문](history/design-through-2026-09-07.md)에 보존한다.

## 게임의 중심

밤하늘을 관측해 데이터를 모으고, 연구와 장비로 관측 능력을 키우는
**유한한 짧은 인크리멘탈**이다. 한 번의 플레이스루에서 성도를 채우고 관측 규모를 넓힌다.

- **기존 하늘과 성도에서 성장한다.** 보류한 천체는 역할과 등장 맥락을 다시 기획하기 전까지 넣지 않는다.
  별도 스테이지·은하 선택 화면·독립 회차로 나누지 않는다.
- **관측 → 정산 → 연구 → 다시 관측**이 기본 리듬이다. 연구 성도는 관측 중에도 열린다.
  좌클릭 유지로 관측과 빈 하늘 훑기를 이어간다.
- **자동화는 성장의 보상이다.** 반복 작업은 장비에 맡기고, 커서는 가장 수율 높은
  장비로 남는다. 정밀 조작 실패에 새 처벌을 붙이는 반사신경 게임으로 바꾸지 않는다.
- **새 연구는 플레이에 차이를 만든다.** 새로 할 일과 관측 대상의 변화가 우선이다.
  시간만 늘리는 가격 벽이나 반복 노드를 추가하지 않는다. 기존 용자리 마지막 강화는
  이미 배운 동사를 크게 보여 주는 승인된 예외다.
- **한 번의 진행이 스스로 완결된다.** 무한 아이들·오프라인 진행·프레스티지와
  반복 플레이를 전제로 한 보상을 기본 구조로 도입하지 않는다.

## 현재 플레이 흐름과 콘텐츠 범위

1. 유성을 관측하고 장비를 연구하면서 기존 별자리 연구 95개를 완성한다.
2. 기존 성도의 바깥에 새 별자리가 드러난다. 같은 성도를 회전·확대하고 별을 길게 눌러
   후속 연구를 설치한다. 확장 이후 기존 12개 별자리의 내부 간격은 75%로 줄여
   크기를 유지한 바깥 별자리와 구별한다. 같은 성도의 실제 연구별과 선택 동작을 유지한다.
3. 은하 기준 좌표계 연구로 모듈 연구와 특수 유성을 연다.
4. 확장 별자리는 13개로 구성한다. 모듈 장착·특수 유성 지원은 2개에 모으고,
   나머지 11개는 항성·소행성·행성·블랙홀·화이트홀을 열고 수동 추적·훑기·연속 관측·연쇄·접시·데이터 분석을
   영구 강화한다. 선행 연구와 데이터로 구매하며 장착이 필요하지 않다.
5. 은하 기준 좌표계 연구 이후 특수 유성 한 종류가 같은 하늘에 나타난다. 일반 유성과 같은
   커서 관측·접시 자동 관측으로 표본을 얻고, 별도 뽑기창에서 표본 8개로 모듈 하나를 뽑는다.
   8종이 같은 확률(각 1/8)로 나오며 중복 보유와 중복 장착을 허용한다. 자동 장착하지 않는다.
6. 활성 모듈 8종은 모두 뽑기로 얻는다. 편성은 처음 2자리,
   최대 5자리다. 같은 모듈의 증감분은 합산한다(+50% 두 개 = ×2.0).
   서로 다른 모듈의 기존 조합 방식은 유지한다. 수집·뽑기는 필수 연구 조건이 아니다.

하나씩 대체한다. 첫 교체는 집중 관측(`focus`)의 속도 +80%를 분열 관측으로 바꾸는 것이다.

개당 30%p씩 합산해 최대 100%로 제한한다. 기존 파편 유성 연구는 유지한다.

2026-09-10 사용자 승인: 궤적 적분기·연계 버스·장기선·이중 처리기·잔광 기록고를

2026-09-10 후속 승인: 포착 고정을 감속 관측으로 변경한다. 관측 중 범위 안 유성의

2026-09-11 과충전 조정: 발동 조건을 12회에서 30회로, 지속 시간을 6초에서 9초로

2026-09-11 사용자 승인: 희귀/대형 화구의 표시 이름을 발광 유성/거대 유성으로 통일한다.

2026-09-11 별자리 교정 승인: 21개 도형 내부의 별 위치를 실제 J2000 좌표의

연구 ID·개수·가격·효과·선행 조건은 유지한다. 성도 전체는 기존 연구 진행용 배치이며
별자리 사이 실제 천구 위치까지 복제하지 않는다. 가까운 별은 좌표를 벌리지 않고
선택 판정으로 처리한다. [좌표 기준과 검증](constellation-geometry.md)을 따른다.

새 별자리를 추가하거나 기존 도형을 바꿀 때도 실제 성도와 별 목록을 먼저 정하고,
별의 개수·상대 위치·연결을 대조한다. 연구 수에 맞춰 별을 임의로 늘리거나 줄이지 않는다.
실행 중인 게임 캡처와 실제 성도·사진을 나란히 비교한 뒤 완료하며,
생략이나 차이가 있으면 숨기지 않고 기록한다. 상세 절차는 같은 좌표 기준 문서를 따른다.

2026-09-13 사용자 승인: 연구 노드가 겹쳐 구분하기 어려운 구간은 실제 별 위치에서
조금 벗어나도 좋으므로 가까운 표식을 벌린다. 카탈로그·별 수·연결은 유지하고,
화면상 최소 간격을 확보하는 표시 보정만 적용한다. 확대할수록 보정량을 줄이며,
공유 별은 하나의 위치와 선택 대상으로 유지한다. 이는 위의 엄격한 상대 위치 기준에 대한
가독성 목적의 승인된 예외이며 새 별 추가나 임의의 별자리 재구성은 포함하지 않는다.

2026-09-13 사용자 승인: 소행성·얼음 소행성의 해금을 확장 이후 화살자리로 옮기고,

이 결정은 아래 첫 블랙홀 구현의 행성 관측 임시 연결과 위의 초기 천체 해금을 대체한다.

## 화면·소리·피드백

2026-09-15 사용자 승인: 디버그 화이트홀을 실제 진행에 연결하고, 블랙홀 이후에
새 별자리를 추가한다. 궁수자리의 블랙홀 관측·추적·분석 뒤 봉황자리에서 해금한다.
봉황자리의 실제 연결 도형 6별을 6개 연구로 사용해 화이트홀의 출현·관측 속도·방출량·
분출물 보상을 강화한다. 후속 요청으로 독수리자리의
보조 별 ζ Aql에도 풍부한 훑기 연구를 연결해 전체는 13개 확장 별자리·67개 후속 연구다.
풍부한 훑기는 긴 훑기 이후 50M에 구매하며 훑기 성공 시 유성 1개를 추가한다.
기존 별의 좌표·연결과 연구 소유권은 유지한다. 별자리 전체 완성이나
모듈 수집 조건은 추가하지 않는다. 기존 회차 길이와 기존 연구의 가격·효과는 유지한다.

화이트홀은 스폰 때 정한 방향으로 이동하고, 관측 완료 시 양극 제트로 다양한 유성을
방출하며 수축·소멸한다. 기본 24개에서 연구로 최대 48개를 방출한다. 방출된 유성은
기존 수동·자동 관측과 보상을 따른다. 작은 밝은 중심, 가스층의 그늘과 움직임·별빛
굴절로 과도하게 화려하지 않은 천체감을 유지한다. 기존 디버그 전용 출현 제한을
이번 승인으로 대체한다. [화이트홀과 봉황자리](white-hole-preview.md)를 참고한다.

2026-09-13 사용자 승인: 확장 이후 기존 별자리를 균일하게 75%로 축소하고,

이는 위의 블랙홀 보류 결정을 이번 설계에 한해 대체한다. 옛 국부은하군 현상·연구나
M31을 복구하지 않는다. [블랙홀 현재 동작](black-hole.md)을 따른다.
후속 사용자 요청으로 렌즈를 주변 유성의 본체·빛·꼬리에도 적용한다. 수동 관측과
선택 표시는 굴절된 중심을 따르고, 실제 이동 경로와 자동 관측 거리는 유지한다.

하늘과 관측 대상이 화면의 주인공이다. 천체는 제 색을 지키고 계기와 UI는
관측소 적색광을 쓴다. 살아 있는 커서 관측 게이지만 중립 백색으로 구분한다.
실제 천체 형상과 연구 상태 표식을 구별하며 관측 공간과 읽을 수 있는 정보량을 지킨다.

일상 관측과 희귀·중요 사건의 강조를 구분한다. 자동화가 강해져도 화면과 소리가
계속 과장되지 않게 한다. 이름은 천문학답게, 효과 설명은 실제 효과와 수치를 짧고
쉬운 말로 쓴다. 한국어와 영어는 같은 동작을 설명한다.

2026-09-12 사용자 승인: 연구 진행에 따라 익숙한 천체의 예보 표시를 단계적으로 줄인다.
분열 유성 연구 후 일반·고속, 인공위성 연구 후 분열·발광, 소행성 연구 후 인공위성의
이름·남은 시간·진입 표식을 숨긴다. 실제 출현과 예측 접시의 자동 배치는 유지한다.

2026-09-12 사용자 승인: 일반·고속 유성의 머리·빛 번짐을 기존 도형에서 구운
공유 애니메이션 텍스처로 시험한다. 미세 형태는 보간된 근사로 표현하되 기존 색·방향·
크기·소멸과 경로를 따르는 꼬리는 유지한다. 다른 종류로 확대하는 것은 이번 범위에 포함하지 않는다.

배치·서체·연출 시간과 세부 표현 기준은 [상세 기준](design-details.md#표현과-설명)에 있다.

## 개발할 때의 결정 범위

**요청받은 작업 안에서 아래 기준으로 진행한다.** 기존 문서에 특정 값이나
화면 배치가 적혀 있다는 이유만으로 모든 수정을 다시 승인받을 필요는 없다.

| 바로 진행하고 결과 보고 | 먼저 사용자와 결정 |
|---|---|
| 버그 수정, 리팩터링, 성능 개선, 검증 보강 | 장르·핵심 조작·관측/정산/성도 흐름 변경 |
| 기존 화면의 가독성·간격·배치와 작은 연출 개선 | 새 콘텐츠 방향, 천체·연구 가지·별도 모드 도입 |
| 기존 기능 안의 소규모 가격·효과·타이밍 조정 | 전체 가격 곡선·성장 속도·목표 완주 시간·엔딩 변경 |
| 현재 계약을 지키는 저장·일시정지·입력 버그 수정 | 저장 호환성 변경, 진행 손실, 자동화와 수동 관측의 역할 변경 |

소규모는 변경한 기능과 인접 동작 안에서 영향이 설명되는 경우다. 핵심 원칙이나
위 오른쪽 항목을 건드리거나, 여러 작은 조정이 합쳐져 전체 진행을 바꾸면 먼저 상의한다.
애매하면 변경 목적·예상 영향과 추천안을 짧게 제시하고 질문한다.

상세 문서의 현재 수치는 조정의 출발점이다. 자율 범위의 변경은 영향과 검증 결과를
보고하고 해당 상세 기준을 갱신한다. 기존 승인 기록은 고치지 않는다. 큰 결정은
사용자 답변과 대체되는 결정을 기록한 뒤 구현한다. 테스트 통과를 설계 승인으로 쓰지 않는다.

## 게임 시간과 출현

사용자 승인(2026-09-11)에 따라 게임 내부는 고정 60틱, 렌더링은 화면 FPS로
분리한다. 자연 천체는 종류별 독립 출현 확률을 가지며 후기 천체 해금이 기존
유성의 추첨 몫을 빼앗지 않는다. 관련 연구는 확률/등장 공간에 연결하되 별자리
위치·개수·연구 ID·소유 기록은 유지한다. GPT-6 Pro 설계와 현재 수치는
[고정 틱 계약](fixed-tick-simulation.md)을 따른다.

2026-09-13 등장 제한 검토·정리 요청: 분열을 막던 공통 대기권 22개 제한을
제거한다. 연구별 활성 관측 한도는 새 자연 등장만 조절하고 분열·모듈 파편
생성을 막지 않는다. 살아 있는 파편까지 세는 기존 자연 등장 조절은 유지한다.
독립 출현 확률·연구 효과·후기 천체 예약은 유지하며, 비정상 폭증에 대비한
전체 70개 안전 상한을 둔다.
2026-09-15 사용자 승인에 따라 항성과 블랙홀의 전용 동시 한도를 각각 1→3으로
늘린다. 완료 잔상도 포함하며 출현 확률·해금·기존 천체의 예약은 유지한다.
상세 배분과 예외는 같은 고정 틱 계약을 따른다.

2026-09-14 사용자 승인: 모듈 해금 시 클릭 위치를 제한하는 첫 사용 튜토리얼을 추가한다.
첫 뽑기용 표본 8개를 슬롯별 한 번 지급하고, 뽑기창 진입 → 뽑기 → 효과 확인 →
보관함의 모듈 클릭으로 빈 자리에 자동 장착하는 조작을 안내한다. 첫 장착 후 자유 편성으로
돌아간다. 진행·지급·추첨 결과를 저장하며, 이미 모듈을 사용한 기존 저장에는 강제 안내나 추가 지급을 하지 않는다.
설정·저장 슬롯 접근은 유지한다. 연구 가격·데이터 보상·회차 길이는 이번 범위에서 유지한다.

2026-09-14 사용자 구현 승인: 확장 초반에 항성용 별자리와 항성 시스템을 추가한다.
방패자리의 첫 연구로 항성을 해금하며, 관측 완료 시 초신성이 주변 유성·특수 유성·
소행성·얼음 소행성·행성을 즉시 관측한다. 다른 항성과 블랙홀은 제외하고, 폭발 중
생성된 새 파편은 같은 폭발에 포함하지 않는다. 블랙홀은 후반 목표로 기존 경로를
유지하며 항성 바로 다음 해금으로 옮기지 않는다. 항성은 일반 천체 파이프라인의
새 종류이며 과거 M31·국부은하군 관측이나 폐지된 항성 시스템의 복구가 아니다.
기존 항성 보류 결정을 이 구현 범위에서 대체한다. 현재 후속 연구는 12별자리·60개,
전체 연구는 155개다. [가격·판정·실제 별자리 기준](stellar-supernova.md)을 따른다.

## 아직 결정하지 않은 것

2026-09-14 사용자 승인: 기존 95개와 외곽 55개 연구 전체의 가격과 데이터 보상
배율을 조정한다. 보통 한 판에 연구 1~2개를 구매하는 경제를 목표로 하되, 저축과
큰 수입에 따른 추가 구매는 허용한다. 구매 개수 제한을 추가하지 않는다. 가격은
1M→1.8M처럼 읽기 쉬운 단위, 배율은 +50%→+25%처럼 명확한 단계로 정하며
측정값에 맞춘 자잘한 끝자리 보정은 하지 않는다. 이번 범위에서는 조작·연구 선행·
천체 출현·시간·모듈 뽑기 규칙을 유지한다. 이 승인은 이전의 가격·보상 배율 유지
조건을 이번 경제 조정에 한해 대체한다. 전체 길이는 엔딩 결정 전까지 목표로
고정하지 않고 측정 결과로 기록한다.

- 보류한 M31 등의 재기획과 게임 전체의 최종 엔딩. 행성과 블랙홀은 위의 재기획 승인 범위로 구현한다.
- 최종 경제와 목표 완주 시간. 현재는 위의 구매 빈도를 조정하며 총 길이를 합격선으로 두지 않는다.
  새 연구 도착 간격의 기존 기준은 최대 관측 길이의 두 배, 현재 120초 이내다.
  측정 범위와 이전 경로의 기준선은 [검증 문서](performance-probes.md#full-tree-economy)를 따른다.
- 추적 품질 지속음, 더 강한 연구 계열색, 위성/쌍성 크기 등 별도로 보류된 제안.
  작은 조정 권한만으로 보류된 제안 전체를 채택하지 않는다.

완료된 미결 항목은 현재 상태로 바꾸고 결정 근거는 이력에 남긴다. 과거 WIP·폐기안과
옛 50~55분 계측값을 새 구현 요구나 사람의 완주 시간으로 해석하지 않는다.
