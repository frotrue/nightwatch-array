# 마지막 관측

2026-09-17 사용자 승인: 초거대질량 블랙홀 등장 → 직접 관측 → 관측 한계 →
퀘이사 같은 발광과 하늘·성도의 붕괴 → 암전과 마지막 기록으로 게임을 마무리한다.
우주의 실제 파괴인지 관측소의 신호 단절인지는 단정하지 않는다.

## 진입과 보존

기존 95개와 확장 67개 연구를 모두 마치면 관측 화면에 `마지막 관측` 버튼이 열린다.
연구 비용·순서·기존 관측 회차는 유지한다. 버튼을 누를 때만 별도 엔딩 연출을 시작하며,
진행 중인 관측과 모든 일반 천체는 일시정지한다. 엔딩에서는 데이터나 표본을 지급하지 않는다.
모듈 수집이나 새 연구 구매는 요구하지 않는다.

마지막 기록 뒤에는 성도로 돌아가기와 다시 보기를 제공한다. 성도로 돌아가면 기존
관측의 남은 시간과 천체 상태가 이어진다. 초기화나 프레스티지는 하지 않는다.
슬롯에는 별도의 `horizon_ending_seen` 불리언만 추가하며 옛 카탈로그 엔딩 플래그는 재사용하지 않는다.
기존 저장에는 기본값 false를 적용한다. 엔딩 중 저장/종료는 일반 관측 상태를 보존하며
미완료 연출은 이어서 재생하지 않는다. 완료 여부는 마지막 기록의 12초가 지나면 한 번 저장한다.

## 흐름과 입력

기본 흐름은 고요 12초, 등장 18초, 마지막 관측 최소 50초, 측정 한계 10초,
붕괴 28초, 암전 10초, 마지막 기록 12초다. 계속 추적하면 약 2분 20초 뒤 기록이 완성된다.
관측에서는 기존 좌클릭 유지로 거대한 대상의 중심을 추적한다. 자동 관측도 진행을 돕지만
85%까지만 단독 진행하며 마지막 관측에는 직접 입력이 필요하다. 놓쳐도 진행도는 줄지 않는다.
도달할 수 없는 100% 게이지 대신 한계 도달을 명시하고 이후에는 자동 연출로 전환한다.

Esc와 설정 버튼은 연출을 멈추고 기존 설정을 연다. 설정을 닫으면 같은 시점에서 이어진다.
화면 번쩍임 끄기는 전면 발광을 어둡게 제한하며 동작 강도 0%는 배경 휘어짐·회전·
별 궤적을 제거한다. 단계별 페이드와 텍스트는 유지한다. 종료 선택이나 성도 이동이
겹쳐 실행되지 않도록 엔딩이 활성화된 동안 일반 관측·성도 입력을 차단한다.

## 구현과 검증

`scenes/ui/last_observation.tscn`이 고정 화면·재질·오디오를 소유하고
`scripts/last_observation.gd`가 입력과 단계 시계를 관리한다. 블랙홀·원반·제트·광학 왜곡은
전용 셰이더, 성도 연결선과 별 궤적은 기존 절차적 아트 방식으로 그린다.
성도는 현재 카탈로그의 별과 연결을 복사해 시각적으로 변형하며 연구 위치나 판정은 수정하지 않는다.

엔딩 진입·잠금·직접 관측·일시정지·복귀·완료 저장과 구형 슬롯을 회귀 검사한다.
두 렌더러의 단계별 캡처와 무동작/번쩍임 끄기 상태를 확인한다.
영상은 격리된 진단 씬에서 실제 엔딩 컨트롤러를 동일한 속도로 실행하며 관측 입력만 자동 공급한다.
녹화 중 플레이어의 저장이나 설정에는 접근하지 않는다.

검증 결과: Godot 4.7.2에서 빠른 게이트 32개, 전체 연구 경제 검사, Windows export를
통과했다. 엔딩 회귀 검사는 완료 저장의 단일 실행과 디버그 미리보기의 무저장,
설정 중 튜토리얼 차단, 기존 HUD로 입력이 새지 않는 경로도 확인한다.
Vulkan Mobile과 OpenGL Compatibility의 엔딩 단계·설정·한영 기록을 캡처해 확인했고,
두 렌더러에서 기존 배경·유성·완료 입자의 비교 검사 6개도 통과했다.

로컬 검토 자료는 `build/ending_review/`에 있다. 전체 MP4는 1152×648, 30fps,
약 2분 26초이며, GIF는 후반 62초를 768×432, 10fps로 담는다. 두 영상 모두 배속을
바꾸지 않는다. MP4에는 별도로 합성한 저음과 붕괴음이 포함된다. 음향과 연출의
최종 감상은 사용자 영상 검토 대상으로 남긴다.
