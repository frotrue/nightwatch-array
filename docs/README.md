## 새 기록을 남길 때

- 핵심 방향·현재 흐름·결정 경계는 짧은 설계에, 기능별 값은 상세 기준에 둔다.
  구현 책임은 시스템 참조, 실행법과 한계는 검증 문서, 이전 경로 유지 조건은 호환 계약에 둔다.
- 자율 범위의 조정은 해당 상세 기준과 검증을 갱신하고 결과를 보고한다.
  사용자 결정이 필요한 변경은 답변과 대체되는 결정을 이력에 남긴다. 원래 근거를 삭제하지 않는다.
- 같은 결정은 현재 유효한 문장을 갱신한다. 날짜별 변경 사유·완료 작업을 설계 본문에 누적하지 않는다.
- 완료된 작업의 과거 WIP 상태를 현행 안내로 남기지 않는다.
- `build/`의 PNG·WAV·영상은 로컬 파생 산출물이다. 파일 이름이나 과거 PASS 대신
  각 자료의 출처·manifest·실제 파일 해시로 무엇을 보여 주는지 확인한다.
