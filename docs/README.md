# 문서 지도

현재 무엇을 구현하고 있는지와 과거에 무엇을 승인했는지를 분리해서 읽는다.
옛 문서의 `현재`, `승인`, `다음 단계`는 기록 당시를 뜻할 수 있다.
동일 사항에 대한 명시적 후속 승인이 이전 결정을 대체한다.

## 새 기록을 남길 때

- 현행 규칙은 설계에, 구현 책임은 시스템 참조에, 실행법과 한계는 검증 문서에 둔다.
- 설계 변경은 사용자 승인과 대체되는 결정을 함께 적는다. 원래 근거를 삭제하지 않는다.
- 완료된 작업의 과거 WIP 상태를 현행 안내로 남기지 않는다.
- `build/`의 PNG·WAV·영상은 로컬 파생 산출물이다. 파일 이름이나 과거 PASS 대신
  각 자료의 출처·manifest·실제 파일 해시로 무엇을 보여 주는지 확인한다.
