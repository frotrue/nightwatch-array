## 완료 작업과 역사 기록

[아카이브 지도](history/README.md)에서 승인 원문, 완료된 계획·조사, 과거 계측과
정리 전 참조를 찾는다. 과거의 `현재`·`승인 대기`·`다음 단계`는 당시 상태이며,
새 작업 지시나 현행 합격선이 아니다. 일상 개발에 아카이브 전체를 읽을 필요는 없다.

## 갱신 규칙

- 현재 유효한 문장을 갱신한다. 날짜별 경과나 완료 작업을 현행 문서에 누적하지 않는다.
- 핵심 방향은 설계, 값은 상세 기준, 구현은 시스템, 검증 명령은 해당 검증 문서에 둔다.
- 소규모 조정은 설계의 자율 범위 안에서 진행·검증·보고한다. 큰 변경은 사용자 답변과
  대체 결정을 기록한 뒤 반영한다. 원래 승인·측정 근거는 보존한다.
- 완료된 계획과 시점별 계측은 `history/`로 옮기고 링크를 함께 고친다.
  기록 당시의 수치·환경·시드·한계를 현재 값으로 덮어쓰지 않는다.
- `build/` 자료는 로컬 파생 산출물이다. 파일명이나 과거 PASS 대신 manifest·소스·
  실제 해시를 확인하고 필요한 자료를 재생성한다.
