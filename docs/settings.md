# 설정·조작 참조

현재 설정창의 항목과 입력·저장 계약이다. 소규모 조정 범위는 [설계](design.md#개발할-때의-결정-범위),
검사는 [probes.md](probes.md), 승인·조사 근거는 [아카이브](history/README.md)에 있다.

## 화면과 항목

HUD 버튼과 Esc가 같은 설정창을 연다. 현재 관측을 일시정지하고 헤더에 이를 표시한다.
왼쪽 메뉴와 한 개의 본문으로 다음 여섯 페이지를 제공한다.

| 페이지 | 현재 기능 |
|---|---|
| 일반 | 언어, 숫자 표기(축약·과학적), 튜토리얼 |
| 소리 | 전체 음량·음소거, 다른 창 사용 시 임시 음소거 |
| 화면 | 창/전체 화면, VSync, 30/60/120/무제한 FPS, 성능 모니터 켜기/끄기 |
| 접근성 | 카메라 밀림·흔들림 강도, 전체 화면 관측 섬광 |
| 조작 | 조작·연구 선행 조건 안내, 키보드 재지정·제거·복원 |
| 저장 | 활성 슬롯, 60초 자동저장 정책, 최근 저장/실패 상태와 확인을 거치는 슬롯 작업 |

어느 일반 페이지에서든 Esc 한 번으로 설정을 닫는다. 키 입력 대기와 확인창은
먼저 닫는다. 마지막 페이지·페이지별 포커스·설정 전 포커스를 복원하며 모달 창은
기존 정산·성도·튜토리얼이 소유한 일시정지를 해제하지 않는다.

카메라 강도 0은 진행 중인 kick·shake도 제거한다. 섬광 끄기는 링·입자·배너·음향을
유지한다. 비활성 창 음소거는 저장된 음소거 값을 바꾸지 않으며 FPS 상한은 포커스와 무관하다.
동작 강도는 항성 표면·아지랑이, 행성 대기, 소행성 자전과 얼음 내부 움직임에도 적용한다.
0%에서는 해당 움직임이 멈추며, 섬광 끄기는 얼음의 재질 반짝임과 천체 완료 빛도 줄인다.
현재 설정 보조문구는 1152×648 기준 12px 이상, 상호작용 문구는 14px 이상이고,
낮은 우선순위 정보도 `INK_MID` 이상의 대비를 쓴다. 슬라이더 포커스는 굵기·외곽선으로도 표시한다.

## 성능 모니터

기본 꺼짐이며 `performance/monitor_enabled`에 저장한다. 화면 오른쪽에 작은 패널을
표시하고 마우스 입력은 통과시킨다. 설정창에서는 패널을 숨기되 측정은 유지한다.
F9의 기존 디버그 HUD와 별개이며 진행·시간 배율·저장 데이터에 영향을 주지 않는다.

- FPS·평균 프레임 시간: 실제 경과 시간 기준 0.5초 구간. 그래프는 각 구간의 가장
  긴 프레임을 최근 60구간까지 보여주며, 최대값도 같은 구간 이력 기준이다.
  기준선은 16.7ms(60 FPS)다. 심한 지연 시 그래프의 실제 시간 범위는 30초보다 길 수 있다.
- CPU: 이 게임 프로세스가 사용한 CPU 시간 / 실제 시간 / 전체 논리 프로세서 수.
  GPU: 이 게임 PID의 모든 GPU 엔진 중 가장 바쁜 엔진 사용률. Vulkan의 Graphics·Compute와
  OpenGL의 3D 등을 포함하며, 동시 실행 엔진을 합산하지 않는다. 다른 앱이나 전체 PC 사용량은 아니다.
- 틱: 실제 게임 틱 증가량을 초당으로 환산한 값과 목표 60틱. 처리 시간은 Godot의
  전체 physics 처리 시간이다. 정산·설정 등 일시정지 중에는 일시정지로 표시한다.
- 천체 수·그리기 횟수: 현재 천체 노드 수와 프레임당 draw call 수.

Windows 측정기 `NightwatchMetrics.exe`는 켰을 때만 별도 프로세스로 실행한다.
Windows GetProcessTimes/PDH를 1초마다 읽고 비차단 파이프로 전달한다. 게임의
시뮬레이션 작업자 상한(주 스레드 + 최대 3개)은 그대로다. 끄거나 씬을 종료하면
측정기도 종료하며, 게임이 비정상 종료해도 부모 프로세스 종료를 감지해 끝난다.
지원되지 않는 OS·GPU 카운터, 측정기 누락, 4초 이상 새 응답 없음은 `—`로 표시한다.
첫 응답 전에도 `—`를 표시하며 실제 0%와 구분한다. 배포 시 두 exe를 함께 제공한다.

## 입력과 우선순위

| 액션 | 고정 입력 | 편집 입력 | 컨텍스트 |
|---|---|---|---|
| `nw_observe` | LMB | 없음 | 관측 |
| `nw_dish` | RMB | 없음 | 관측 |
| `nw_chart` | 없음 | U | 관측·성도 |
| `nw_menu_back` | Esc | 선택 보조키 | 관측·성도·설정·대화상자·정산·기록 |
| `nw_continue` | Enter·Space | U | 정산 |
| `nw_fullscreen` | 없음 | F11 | 전역 |

`GameInputRouter._input()`이 재지정 후보를 GUI보다 먼저 소비한다. 그 외 전역 입력은
`_unhandled_input()`에서 처리한다. 성도 닫기와 카탈로그 미리 보기 입력은 각 화면이
먼저 처리하며, 모듈 팝업이 열리면 성도가 입력을 양보한다.
전역 처리 순서는 입력 대기 차단→전체 화면→메뉴/뒤로→정산 계속→성도 열기다.
라우터·HUD·설정·튜토리얼과 성도는 필요한 입력을 일시정지 중에도 처리한다.
`F9`와 `Ctrl+Shift` 디버그 단축키도 라우터가 전달하므로 성도·정산·모듈창의
일시정지 중에 동작한다. 키 재지정 대기·시작 슬롯·모달 튜토리얼에서는 실행하지 않는다.
`Ctrl+Shift+A`는 기존 95개와 확장 60개 연구를 모두 해금하며 기존 연구만 완료된
저장에서도 확장을 채운다. 확장 효과·장착 자리·저장도 함께 갱신한다. 모듈 사본은
지급하지 않으며 전체 해금 뒤 다시 누르면 연구나 데이터를 중복 지급하지 않는다.

재지정은 키보드만 받으며 Esc로 취소한다. 반복·수정키 단독·포인터·패드 입력으로
완료하지 않는다. 후보 누르기와 해당 키 놓기를 모두 소비해 새 액션이나 포커스 버튼에
전달되지 않게 한다. 컨텍스트가 겹칠 때만 충돌로 판정하므로 성도/정산의 U 공유는 유효하다.
GUI 이동키·디버그 조합은 예약하고 메뉴 보조키·전체 화면에는 Enter·Space 계열도 허용하지 않는다.
선택 보조키 제거는 그 슬롯만 비운다. 우클릭 접시 배치는 Shift가 함께 눌려도 같은 동작이다.

시작 슬롯·엔딩·모달 튜토리얼은 전역 성도/뒤로 진입을 막는다. 정산 위에는 설정을 열 수 있지만
튜토리얼 재생은 막는다. 성도에서 Esc는 성도를 먼저 닫는다. 모달 복귀는 원래 포커스와 pause를 보존한다.

## 저장

`GameSettings`는 `user://settings.cfg`, `SETTINGS_VERSION = 3`을 사용한다.
설정은 검증 후 즉시 적용·저장한다. 런 슬롯의 `SAVE_VERSION = 1`과 별개다.

| 섹션 | 저장 값 |
|---|---|
| `accessibility` | `language`, `motion_intensity`, `screen_flashes_enabled` |
| `onboarding`, `research_chart` | `tutorial_completed`, `rotation` |
| `audio` | `master_linear`, `muted`, `mute_when_unfocused` |
| `display`, `performance` | `fullscreen`, `vsync_enabled`, `fps_limit` |
| `display` | `number_notation` (`compact` 기본값 또는 `scientific`) |
| `input` | 여섯 액션의 편집 가능한 키 descriptor 배열 |

로드 시 기본값과 고정 입력을 먼저 복원한 뒤 유효한 편집값만 적용한다. 잘못되거나 충돌하는
입력은 해당 액션만 기본값으로 돌리며, 다른 사용자 설정과 무관한 InputMap 액션은 보존한다.
바인딩 변경은 성도 키 안내·HUD·튜토리얼을 갱신한다. 테스트 경로는 `_ready()` 전에 주입한다.

## 숫자 표기

2026-09-08 사용자 승인: 데이터가 100만 이상이면 유효숫자 3자리로 축약한다.
기본 표기는 M(백만)·B(십억)·T(조)이며, 과학적 표기는 `1.20e9` 형태다.
예를 들어 60,000,000은 `60.0M` 또는 `6.00e7`, 1,200,000,000은 `1.20B` 또는 `1.20e9`다.
100만 미만은 쉼표로 구분한 전체 값을 유지하고 분당 데이터는 소수 한 자리를 유지한다.
축약 범위를 넘는 10^15 이상은 두 설정 모두 과학적 표기를 쓴다.

HUD 보유량·획득량, 성도 보유량·연구 비용·부족 안내, 정산 데이터·분당 데이터·증감과
저장 슬롯 데이터에 동일하게 적용한다. 마우스를 올리면 축약하지 않은 값을 볼 수 있다.
설정 변경은 열린 화면에도 즉시 적용되며, 저장된 값이 없거나 잘못되었으면 축약을 사용한다.
표시만 반올림한다. 실제 보유량·구매 가능 여부·보상 계산·런 저장값은 그대로 사용한다.

## 후속 범위

UI 배율·고대비/색각 프리셋·전역 모션 감소·입자 밀도·포인터 대체 조작·완전한 패드 지원,
음악 슬라이더·해상도 선택·cloud/import/export는 현재 기능에 포함되지 않는다.
특히 판정 반경·hold 규칙·저장 호환성에 영향을 주는 확장은 설계의 결정 경계를 따른다.
