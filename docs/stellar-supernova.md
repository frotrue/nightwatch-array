# 항성과 초신성

구분했다. 항성 관측 완료 시 초신성이 주변 천체를 즉시 관측한다. 폭발에는 유성류뿐
아니라 소행성·얼음 소행성·행성도 포함한다. 기존에 폐지한 항성·M31 시스템을 복구하지
않고 일반 천체 파이프라인에 `stellar`를 추가했다.

## 방패자리와 진행

2026-09-15 후속 구현: 광역 초신성 연구는 기존 효과와 함께 초신성 후 중성자별 잔해를
35% 확률로 남긴다. 항성과 중성자별이 3자리를 공유한다. 새 연구별은 추가하지 않는다.
초신성의 동심원·규칙적인 방사형 선은 불규칙한 가스층 셰이더로 교체했으며 기존
관측 판정·반경은 유지한다. 현재 완료 연출은 아래의 수축·폭발 2초이며,
[중성자별의 현재 동작과 검증](neutron-star.md)을 참고한다.

은하 기준 좌표계 이후 별자리 완성·모듈 보유 조건 없이 방패자리의 첫 연구를 구매한다.
블랙홀은 기존 화살자리 → 게자리 → 궁수자리 경로와 가격을 유지한다.

| 연구 | 가격 | 선행 | 효과 |
|---|---:|---|---|
| 항성 관측 | 15M | 은하 기준 좌표계 | 항성·초신성 해금 |
| 충격파 확장 | 25M | 항성 관측 | 폭발 반경 180 → 240 |
| 항성 추적 | 30M | 항성 관측 | 항성 수동·자동 관측 속도 +30% |
| 항성 탐색 | 35M | 항성 추적 | 항성 출현 확률 +35% |
| 광역 초신성 | 45M | 충격파 확장 + 항성 탐색 | 폭발 반경 240 → 300, 항성 데이터 +25% |

방패자리 5개 연구 총 150M. 현재 전체는 **기존 95 + 후속 60 = 155개 연구**,
**24개 별자리·163표식·162고유 천체**다. 기존 150개 연구의 가격·효과는 유지한다.

## 항성 동작

- 독립 60틱 추첨의 기본 확률은 `0.025 / 60`이다. 공통 출현 배율과 항성 전용
  출현 배율을 적용한다. 기존 종류의 추첨 순서·난수 스트림은 그대로 두고 항성을 끝에 추가했다.
- 기본 이동 속도 30, 수명 32초, 관측 시간 4.2초, 데이터 160, 본체 반경 96.
  기존 수동 관측·접시·모듈과 자동 관측 규칙을 사용한다. 별도 밝기 타이밍 조작은 없다.
- 항성 전용 3자리에 완료 잔상까지 포함한다. 블랙홀의 전용 3자리와 독립이며
  기존 종류의 자리를 줄이지 않는다. 전체 안전 예산은 70개
  (일반 51 + 후기 15 + 표본 3 + 거대 유성 1, 화이트홀 추가 후 배분)다. 출현 확률은 유지한다.
- 밝은 구체·끓어오르는 표면·자라나는 홍염·주변 아지랑이로 표현한다. 관측 완료 시 총 2초 중
  처음 0.48초 동안 구체가 작은 핵으로 수축하고, 나머지 1.52초 동안 가스층이 폭발 범위까지 퍼진다.
  이는 실제 항성 진화의 시간 축척을
  재현하는 시뮬레이션이 아니라 관측 완료의 게임 효과다.

## 초신성 판정과 보상

- 수동·자동 관측 완료 모두 발동한다. 자연 소멸이나 회차 종료로는 발동하지 않는다.
- 완료 위치의 반경 180 이내에 중심이 있는 **현재 화면 안의 살아 있는 천체**를
  즉시 관측한다. 화면 배율을 월드 거리로 변환하므로 줌에 따라 체감 범위가 달라지지 않는다.
  연구로 반경 240·300까지 넓어진다. 효과는 즉시 적용하며 충격파는 그 결과를 보여준다.
- 일반·고속·분열·발광·거대 유성, 기존 파편, 인공위성·혜성, 소행성·얼음 소행성·행성,
  출현을 마친 특수 유성을 포함한다. **다른 항성·블랙홀·미출현 예보·소멸한 천체는 제외**한다.
- 폭발 대상 목록은 보상 콜백 실행 전에 확정한다. 분열 유성과 분열 모듈이 만든 새 파편은
  같은 폭발에서 관측하지 않으며 기존 모듈 효과와 후속 관측 대상으로 남는다.
- 폭발로 완료한 대상은 자동 관측 계수 0.68과 해당 연구 배율로 기존 보상 경로를 탄다.
  항성 자체의 수동 품질은 정상 적용한다. 폭발이 수동 연속 관측 횟수를 공짜로 늘리지 않는다.
  특수 유성의 표본은 정상 지급하며 완료·데이터·표본을 중복 지급하지 않는다.
- 동작 강도 0과 섬광 끄기는 연출만 줄인다. 실제 폭발 판정·보상은 유지한다.
- 저장 카탈로그는 6. 기존 소유권을 유지하며 새 항성 연구를 자동 지급하지 않는다.
  구형 저장의 기존 난수 스트림은 복원하고 새 항성 스트림만 시드에서 시작한다.
  하늘의 항성·폭발 잔상은 기존 로드·회차 정리 방식대로 비운다.

## 항성 외형

항성은 주황·금색의 자체 발광 구체로 표현한다. 규칙적인 점과 동심원 대신
구면 좌표의 다중 크기 잡음을 겹쳐 불규칙한 밝은 표면과 어두운 흐름을 만든다.
가장자리로 갈수록 부드럽게 어두워지고, 바깥에는 희미한 코로나와 크기·위치가
다른 홍염 고리 3개가 이어진다. 실제 유체나 항성 대기 계산은 아닌 게임용 근사다.

2026-09-15 크기 비율 보정: 항성이 행성보다 작다는 사용자 지적에 따라 기본 반경을
44 → 96으로 늘리고, 유성 기본 축소 0.72 대신 다른 구형 천체와 같은 0.84를 적용한다.
본체 지름은 행성의 약 59%에서 **150%**로 바뀐다. 같은 화면 배율에서 행성은 약
108픽셀, 항성은 약 161픽셀이다. 관측 판정과 선택 표시도 같은 본체 반경을 따른다.
아지랑이는 커진 반경의 3배까지 펼쳐지며 초신성의 실제 관측 범위 180~300은 유지한다.
화면 굴절의 기준 반경도 새 본체에 맞춰, 크기 확대만으로 주변 행성이 과하게 일그러지지 않게 한다.

2026-09-15 애니메이션 보강: 서로 다른 방향의 흐름이 표면 무늬를 변형시켜 밝은
덩어리가 솟고 퍼지는 움직임을 만든다. 홍염은 주기가 다른 3개 고리가 자라났다
잦아들고, 코로나의 작은 불꽃은 바깥으로 흐른다. 수동·자동 관측 진행도에 따라
표면의 밝은 부분과 코로나·홍염·열기가 조금 강해진다. 추가 조작은 필요하지 않다.

`scenes/stellar_surface.tscn`은 표면·열기 셰이더와 뒤버퍼를 소유한다. 셰이더는
표면에 본체 반경 1.8배, 열기에 3.2배의 사각 영역을 사용하고, 본체는 배경을 가린다.
2026-09-15 추가 보강으로 아지랑이는 본체 반경의 1.72배에서 **3배**까지 넓어졌다.
기본 굴절 계수는 1.2 → 5.0픽셀, 관측 완료 직전에는 2.3 → 9.0픽셀로 약 4배 높였다.
화면 배율·동작 강도·등장/소멸 투명도를 적용하며 바깥 경계에서 변위를 0으로 줄인다.
넓은 파동이 주변 별빛과 유성의 몸체·꼬리를 휘게 만든다. 변위만 서서히 줄이고
샘플한 화면을 그대로 덮어써 원래 유성의 선명한 복제상이 겹치지 않게 한다.

일반 천체(z=10)를 모두 그린 뒤 열기용 전체 뒤버퍼 복사와 굴절(z=11)을 실행한다.
항성보다 나중에 생성된 유성에도 적용되며, 이후 같은 층의 블랙홀 렌즈와
블랙홀 본체(z=12)를 그린다. 관측 표시는 이후 레이어에서 그리므로 읽기 쉬운 상태를 유지한다.
열기와 블랙홀 렌즈가 함께 있을 때도 올바른 화면을 읽도록 전체 뒤버퍼를 한 번 갱신한다.
지역 복사로 시험했을 때 이전 프레임 잔상이 발생해
전체 복사로 변경했다. 이는 화면 전체를 왜곡한다는 뜻은 아니다.
[Godot의 뒤버퍼 복사 순서](https://docs.godotengine.org/en/stable/tutorials/shaders/screen-reading_shaders.html)를 따른다.
화면 밖·관측 완료·동작 강도 0%에서는 이 복사를 끈다. 동시 출현은 최대 3개이며 표면·열기·뒤버퍼는 항성별로 독립한다.

움직임은 시뮬레이션 나이를 따르므로 일시정지 때 멈춘다. 동작 강도는 표면·홍염
움직임과 아지랑이에 적용하고, 섬광 끄기에서는 작은 밝기 맥동을 없앤다.
2026-09-16 사용자 요청으로 관측 완료 연출을 **수축 → 폭발**로 바꿨다.
완료 직후 열기는 끄고 표면·홍염을 본체 반경의 16%까지 부드럽게 수축시킨다.
핵의 색은 따뜻한 황백색으로 변하고, 작은 핵에서 반동과 불규칙한 가스층이 빠르게 퍼진다.
섬광 끄기에서는 수축 중 밝기 강조를 생략하며 동작 강도 0%에서는 수축 단계를 생략한다.
더 천천히 웅장하게 터지도록 해 달라는 후속 요청에 따라 전체 시간을 0.9→2초로 늘렸다.
가스층 두께와 밀도를 높이고 팽창을 완만하게 하며, 잔광이 더 오래 남은 뒤 사라진다.

이벤트에서 즉시 처리하고, 수축 이후의 폭발은 그 결과를 표현한다.

## 실제 별자리 기준

형태는 [IAU / Sky & Telescope 방패자리 성도](https://iauarchive.eso.org/static/public/constellations/pdf/SCT.pdf),
좌표는 [Yale Bright Star Catalogue V/50](https://cdsarc.cds.unistra.fr/viz-bin/cat/V/50)의
J2000 값을 사용한다. `tools/data/research-stars.json`에 식별자와 좌표를 기록했다.

| 별 | 카탈로그 | 연구 |
|---|---|---|
| α Sct | HR 6973 | 항성 관측 |
| β Sct | HR 7063 | 충격파 확장 |
| γ Sct | HR 6930 | 항성 추적 |
| δ Sct | HR 7020 | 항성 탐색 |
| ε Sct | HR 7032 | 광역 초신성 |

기준 연결 도형 **5별 = 게임 5별**, 연결은 α–β–ε–δ–γ–α다. 성도에 표시된 ζ·η와
M11·M26은 이 연결 도형의 꼭짓점이 아니며 연구 수에 맞춰 생략한 별이 아니다.
공유 별·가상 표식은 추가하지 않았다. 동일 입체 투영·균일 축척을 적용하며 앵커는
반경 760·각도 −2.65, 축척 110이다. 이는 연구 화면 배치이며 실제 천구상의 이웃을
재현하지 않는다. 가까운 δ·ε는 기존 승인된 화면 가독성 보정만 적용한다.
